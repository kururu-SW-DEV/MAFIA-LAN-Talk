# v1.24 — 투표버튼 클릭 후 집계 지연 체감 완화 (2026-09-18)

## 사용자 지적
"투표버튼 누를때 프리징 이거 해결 된거 맞니? 집계가 늦어서 그런거 같은데"

## 원인 (실측 확정)

유저가 투표를 접수해도 **AI 미투 표**가 남아 있으면 all_voted가 늦게 True가 됨.
AI 표 스케줄(첫 표 0.3초 + 이후 0.35초 간격)과 카운트다운 tick이 겹치면서
**유저 클릭 → 개표(피고인 확정)까지 평균 ~2.1초** 걸림 (실측).
이 2초 구간 동안 반응이 없어 '프리징'으로 체감. 추가로 개표가 완료되면
60초 변론 기간에 들어가는데 해당 안내 없이 조용해 '멈춤'처럼 보임.

## 조치 (v1.24)

| 항목 | 내용 |
|---|---|
| AI 표 가속 | 유저 표 접수 직후 남은 AI 표를 **0.15초 간격 즉시 접수** (기존 0.3~0.35초 간격 유지 조건 재활용) |
| 개표 완료 안내 | 피고인 확정 직후 "🗳 개표 완료 — 60초 변론 진행 중입니다 (멈춘 아님)" 시스템 라인 표시 |
| 클릭 피드백 유지 | 보라색 "✓ 이름"="+ 0.5초 후 닫기" | 
| 안전망 유지 | 8초 후 강제 개표 + 60초 변론 + 30초 찬반 |

## 실측

```
개표 완료 안내 등록 확인 — _open_defense_for에 삽입
AI 가속 스케줄 — 유저 접수 직후 미투 AI 있으면 150ms 후 접수 트리거
컴파일 OK, 배포 30.05MB, 스모크 PASS
```
