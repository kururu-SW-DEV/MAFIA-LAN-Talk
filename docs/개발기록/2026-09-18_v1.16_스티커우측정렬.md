# v1.16 — 내 스티커(이모티콘) 우측 정렬 (2026-09-18)

## 사용자 지적
"내가 보내는 이모티콘도 채팅창에서 좌측정렬이네"

## 원인 (실측 확정)

`chat_renderer.py` `_draw_sticker_item` — 랜톡 v6.48 원본에서 스티커는
"좌측 정렬 통일" 주석과 함께 mine 여부 무관 항상 좌측에 그렸음:

```
cx = (MARGIN_SIDE + r) if mine else (PEER_BUBBLE_X + r)
```

텍스트 말풍선은 mine 우측 정렬이지만 스티커만 좌측으로 빠졌다.

## 조치 (v1.16)

| 항목 | 내용 |
|---|---|
| 정렬 일치 | `cx = (w - MARGIN_SIDE - r) if mine else (PEER_BUBBLE_X + r)` — 내 스티커 우측 마진(12px) 위치, 텍스트 말풍선과 동일 기준 |
| 상대 스티커 | 기존 좌측 유지 |

## 실측

채팅 폭 460px 기준: mine cx = 400 → 스티커 우측 첨단 448 = 우측 마진 일치(텍스트 말풍선과 동일).
컴파일 OK, 배포 30.05MB 스모크 PASS.
