# v6.6 포터블 실행 지원 — 데이터 저장 위치를 프로그램 폴더 기준 상대 경로로 변경 (2026-09-13)

- **사용자 요청**: "대화 기록 및 시크릿 키가, 현재 프로그램 코드에 있는 폴더로 지정해줘. 이
  프로그램은 포터블로 들고 다닐 거니깐, 상대참조로 보관될 수 있도록 해줘." — USB 등에 폴더째
  넣어 여러 PC를 오가며 써도 대화 기록이 항상 따라오게 해달라는 요청.
- **기존 문제**: `secret.key`는 이미 `app_dir()`(프로그램 소스 폴더, `os.path.dirname(
  os.path.abspath(__file__))`로 매번 새로 계산)에 있어 원래부터 포터블했지만, 대화 기록·
  설정·`groups.json`·`outbox.json`·`debug.log`·다운로드 파일을 담당하는
  `default_datadir()`는 `%LOCALAPPDATA%\KariLanChat\`(Windows 사용자 프로필에 고정된 절대
  경로)를 썼다. 이 폴더를 통째로 다른 드라이브·PC로 옮기면 새 환경의 `%LOCALAPPDATA%`가
  완전히 다른 사용자 계정을 가리켜서, 기존 대화 기록에 전혀 접근할 수 없었다.
- **수정 (`netutils.py`)**: `default_datadir()`가 `os.path.join(app_dir(), "data")`를
  반환하도록 변경. `app_dir()`과 동일하게 `__file__` 기준으로 매 호출마다 새로 계산하므로,
  USB 드라이브 문자가 바뀌거나(`E:\` → `F:\`) 폴더를 통째로 다른 PC에 복사해 실행해도 "지금
  실행 중인 바로 그 폴더" 밑의 `data/`를 정확히 찾는다. `secret.key`는 원래 위치(`app_dir()`
  루트) 그대로 두어 기존 배포 관행(폴더 복사 시 자동 공유)을 깨지 않았다.
- **기존 실사용 데이터 마이그레이션**: 이 PC에 실제로 쌓여 있던 `%LOCALAPPDATA%\KariLanChat\`
  (그룹 38개, 대화 로그, 아바타, 설정, 59KB짜리 `debug.log` 등 실사용 흔적)를 새 `data/`
  폴더로 전체 복사했다. 원본은 삭제하지 않고 그대로 남겨뒀는데, 이유는 이 작업 시점에 구코드를
  이미 메모리에 올려 실행 중이던 프로세스(`lan_messenger.py`, 그날 아침부터 기동)가 여전히
  구 경로에 읽고 쓰고 있었기 때문 — 그 프로세스가 살아있는 동안 원본을 지우면 그 세션이
  즉시 파일을 못 찾아 오류를 낼 수 있어, 사용자가 재실행으로 새 코드를 확인한 뒤 직접 정리하도록
  안내만 하고 실제 삭제는 보류했다.
- **배포 시 주의사항 문서화**: `data/`에는 이제 실제 개인 대화 기록이 들어가므로, 동료에게
  프로그램 폴더를 나눠줄 때 `secret.key`(공유 필요)는 포함하되 `data/`(개인 기록)는 반드시
  제외해야 한다는 점을 README에 명시했다 — 이전에는 대화 기록이 사용자 프로필에 있어 폴더
  복사만으로는 실수로 같이 딸려갈 위험이 없었지만, 이제는 같은 폴더 안에 있으므로 이 위험이
  새로 생겼다.
- 검증: `python -m py_compile`(변경 파일) + `test_headless.py`/`smoke_gui.py`/`test_gui_flow.py`
  3종 무인 테스트(모두 격리된 임시 datadir을 쓰므로 이번 변경과 무관하게 통과) + 실제 `Engine`을
  새 `default_datadir()`로 띄워 마이그레이션된 `groups.json`(그룹 38개)·`secret.key`(32바이트)가
  정상적으로 로드되는지 별도 스크립트로 직접 확인.
