# v1.53 — 앱 기동 시점부터 1400x800 + 팝업 중앙 정렬 최종 수정 (2026-09-19)

## 사용자 지적
(역할 팝업이 오른쪽으로 치우친 스크린샷 첨부) "게임시작전인 어플 기동시
부터 1400:800으로 해줘. 그리고 이거도 팝업이 치우쳐져 있네 사이드바 여부
상관없이 정중앙으로 바꿔줘"

## 조치

**해상도**: `app.py` `App.__init__`의 `root.geometry("450x800")`(9:16 기본값)를
화면 정중앙 `1400x800`으로 변경 — 마피아 게임방에 들어가길 기다릴 필요
없이 앱을 켜는 순간부터 적용.

**팝업 정렬**: v1.49에서 도입한 "대화 영역(`chat_wrap`) 기준 중앙 정렬"을
되돌림 — 사이드바 렌더 타이밍/유무에 따라 오히려 반대쪽(오른쪽)으로
치우쳐 보이는 부작용이 있었다. `_make_embed_dialog`(dialogs.py)와
`_mafia_show_splash`(mafia_ui.py) 모두 다시 `self.root`(창 전체) 기준
단순 `relx=0.5` 정렬로 복귀 — 사이드바 유무와 무관하게 항상 창 정중앙.

## 검증

앱 기동 직후(마피아 상호작용 전) `root.winfo_width/height()`가 1400x800으로
뜨는 것 확인. 역할 팝업을 화면 캡처해 1400px 창의 정확한 중앙(≈700px)에
뜨는 것 확인(스크린샷으로 사용자에게 전달). 기존 회귀 테스트 재확인.
