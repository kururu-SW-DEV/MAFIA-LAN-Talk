# v1.31 — 최후변론 유저 '사칭' 변론 제거 (2026-09-18)

## 사용자 지적
"최후변론시 왜 나를 사칭하는 AI가 나와서 나를 변론해?"

## 원인 (코드 실측 확정)

유저가 피고인일 때, 변론 안전망(`_defense_fallback`, 6초)이 **피고인
구분 없이** 기본 변론문을 큐에 주입 → 폴러가 그 문구를 **유저 이름의
말풍선**으로 렌더 → 유저가 직접 변론하기 전에 "저는 마피아가 아니라고
확신합니다" 같은 AI가 만든 문구가 '나'라는 사람으로 채팅에 뜸 = 사칭.

(유저 변론은 '직접 타이핑' 방식 — AI 변론 대상이 아니므로 이 문구는
그대로 유저 사칭으로 노출되는 유일 경로였음.)

## 조치 (v1.31)

| 항목 | 내용 |
|---|---|
| 안전망 조건 분기 | 유저가 피고인이면 기본 변론문 주입 금지 — 안내문만 표시 "(안내) 변론 기간 중입니다 — 채팅으로 직접 변론하세요 (60초)" |
| 폴러 이중 방어 | 변론 큐 항목이 '유저 본인 이름'이면 렌더 자체를 스킵 — 다른 경로로 재유입돼도 차단 |
| AI 피고인 변호유지 | AI 피고인 3회 분할 변론(0.5/20/40초) — 그대로 |

## 실측 (E2E)

```
유저 피고인: 사칭 변론 문구 검출 False, '직접 변론하세요' 안내 True
AI 피고인: 변론 말풍선 정상 렌더 (사칭 아님 — 라벨 김과장)
```
