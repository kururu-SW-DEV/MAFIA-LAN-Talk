# v6.1 상용 메신저급 9대 핵심 기능 도입, 원형 아바타 4x4 서브픽셀 앤티앨리어싱·완전 투명화, 클립보드 캡처 전송 완벽 개편 (2026-09-12)

- **상용 메신저급 9대 핵심 편의·신뢰성 기능 구현**:
  - **1) 클립보드 스크린샷 붙여넣기 (`Ctrl+V`)**:
    - `Win + Shift + S` 등으로 캡처하거나 복사한 이미지를 대화창에서 `Ctrl+V` 즉시 이미지 파일로 변환하여 전송.
    - 입력창뿐 아니라 대화 캔버스 및 창 전역 어디서든 `Ctrl+V` 입력 시 즉각 전송 지원.
  - **2) URL 링크 자동 인식 및 원클릭 브라우저 열기**:
    - 말풍선 본문 내 `http(s)://` 등 웹 링크를 정규식(`URL_REGEX`)으로 실시간 감지하여 소프트 블루(`C_LINK`, `#60a5fa`)로 하이라이트.
    - 더블 클릭 및 우클릭 컨텍스트 메뉴의 `[🔗 링크 열기]`를 통해 OS 기본 웹 브라우저(`webbrowser.open`)로 즉시 연결.
  - **3) 대화방 내 인룸 검색 (`Ctrl+F`)**:
    - 대화방 상단에 플로팅 슬림 검색 바(`ChatSearchBar`) 탑재.
    - 실시간 키워드 매칭, 일치 개수 표시(`1/5`), 이전(`▲` / `Shift+Enter`), 다음(`▼` / `Enter`), `ESC` 닫기 지원.
    - 검색된 말풍선 위치로 캔버스가 부드럽게 자동 스크롤되며 하이라이트 표시.
  - **4) 인용 답장 (Quote Reply)**:
    - 말풍선 우클릭 시 `[답장]` 메뉴 제공. 선택 시 입력창 상단에 파란 액센트 바의 `ReplyBanner` 노출.
    - 메시지 전송 시 `reply` 필드를 패킷에 포함하여 상대방에게도 원본 발신자와 인용 문구가 카드 형태로 함께 렌더링.
  - **5) 오프라인 아웃박스 재전송 큐 (Outbox Retry)**:
    - 상대방 오프라인 또는 네트워크 일시 단절로 ACK 수신에 실패한 메시지를 `outbox.json` 파일에 안전하게 영속화.
    - 백그라운드 워커가 상대방의 `presence` 하트비트를 감지하는 즉시 큐를 자동 플러시하여 재전송 완료.
  - **6) 카카오톡 스타일 실시간 읽음 확인 (`1` 배지)**:
    - 내가 보낸 메시지(`dir == "out"`)에 `unread=True` 플래그를 부여하고 시각 라벨 앞에 앰버색 `1` 숫자 배지 표시.
    - 상대방이 해당 대화창을 선택하여 활성화하면 즉시 `read_ack` 패킷을 맞보내어 `1`이 실시간으로 사라짐.
  - **7) 서버리스 분산 그룹 나가기 프로토콜 (`group_leave`)**:
    - 그룹 헤더의 `[⚙ 설정]` 메뉴에서 `[🚪 그룹 나가기]` 선택 시 로컬 방 삭제 및 잔여 멤버 대상 `group_leave` 패킷 브로드캐스트.
    - 잔여 멤버들의 화면에는 `"... 님이 대화방을 나갔습니다."` 중앙 시스템 메시지가 표시되고 로스터가 실시간 갱신.
  - **8) 보스키 (Panic Hide / Restore)**:
    - 메신저 실행 중 `Ctrl + Shift + H` 또는 `F12`를 누르면 창이 바탕화면과 작업표시줄에서 즉시 완전히 숨겨짐(`withdrawn`). 단축키를 다시 누르면 즉시 복원.
  - **9) 유휴 시간 기반 자리비움(Away) 상태 감지**:
    - Windows API `GetLastInputInfo`를 통해 시스템 전역 키보드/마우스 유휴 시간을 주기적으로 측정.
    - 5분(300초) 이상 입력이 없으면 `presence` 패킷 상태가 `"online"`에서 `"away"`로 자동 전환되며, 상대방 목록과 헤더에 주황/앰버색(`C_AWAY`, `#f59e0b`) 점과 `"자리비움"` 텍스트로 표시.

- **원형 아바타 4x4 서브픽셀 앤티앨리어싱 및 완전 투명도(True Alpha) 개편**:
  - **단체방 이중 원 투명화 (`app.py:_avatar_group`)**:
    - 기존에 사이드바 배경색(`C_SIDEBAR`, `#1c1d21`)의 2px 불투명 외곽선(`ring_hex`)이 PNG에 구워져 겹치는 원이나 선택 배경(`C_ROWSEL`, `#383b44`)에서 검은 링이 겉돌던 결함을 완전히 해소.
    - 불투명 테두리를 제거하고 순수 기하학적 100% 알파 투명도(`alpha=0`) 마스크를 적용.
    - 두 멤버의 색상이 같거나 1명인 경우 `C_AVA` 팔레트에서 대비되는 다른 색상을 자동 배정하여 테두리 없이도 두 원이 자연스럽게 구분.
  - **채팅창 내부 아바타 매끄러운 렌더링 (`app.py:_draw_label`, `_draw_record`)**:
    - Windows Tkinter Canvas의 `create_oval`이 가진 GDI 1비트 래스터화(거친 계단 현상)를 제거.
    - 4x4 서브픽셀 슈퍼샘플링(16샘플)으로 정밀하게 앤티앨리어싱된 `smooth_circle_photo`를 캔버스에 `create_image`로 배치하여 원 둘레가 극도로 매끄럽고 바깥은 100% 투명하게 렌더링.
    - 상대방이 프로필 사진을 등록한 경우(`rec.get("av")` / DM 상대 프로필 해시) 등록된 원형 사진이 부드럽게 표시되고, 기본 아바타일 경우 매끄러운 원형 위에 이니셜이 정중앙에 배치.
    - 파일 전송 카드(`_draw_file_item`)의 원형 아이콘도 동일하게 매끄러운 서브픽셀 원형으로 업그레이드.
  - **사용자 등록 프로필 사진 크롭 마스크 품질 개선 (`netutils.py:make_circular_avatar_png`)**:
    - 기존 1비트 `transparency_set` 마스크 대신 4x4 서브픽셀 슈퍼샘플링 RGBA PNG 인코더를 적용하여 등록 사진도 가장자리가 부드럽게 마스킹.

- **클립보드 이미지/파일 붙여넣기(`Ctrl+V`) 로컬 경로 노출 버그 완벽 수정**:
  - **원인**: Windows 캡처 도구(`Win + Shift + S`) 및 파일 탐색기 복사는 클립보드에 파일 드롭 목록(`CF_HDROP`) 형식으로 데이터를 저장함. 기존 코드는 인메모리 `PIL.Image.Image`만 체크하여 파일 목록(`list`)을 건너뛰었고, 텍스트 클립보드 폴백에 의해 파일 경로 문자열(`C:\Users\...\TempState\ScreenClip\...png`)이 대화 입력창에 텍스트로 타이핑되던 문제 발생.
  - **해결**:
    - `netutils.py:get_clipboard_files()`를 신설하여 `ImageGrab` 파일 리스트 및 Windows 순수 API(`CF_HDROP` + `DragQueryFileW`)로부터 실제 로컬 파일 경로 목록을 정확히 추출.
    - `app.py:_on_entry_paste()` 파이프라인을 개편하여 클립보드에 파일이 있으면 경로 텍스트를 적지 않고 `self._send_file_path()`로 파일/이미지 즉시 전송.
    - Windows ScreenClip 임시 파일의 경우 임의 UUID 이름 대신 직관적인 `screenshot_YYYYMMDD_HHMMSS.png`로 자동 보존 복사 후 전송.
    - 클립보드 텍스트 자체가 로컬 파일 경로인 경우에도 파일로 자동 감지 전송.
