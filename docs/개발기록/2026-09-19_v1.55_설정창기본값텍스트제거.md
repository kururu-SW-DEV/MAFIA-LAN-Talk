# v1.55 — 설정창 서버 URL/모델명 기본값 텍스트 제거 (2026-09-19)

## 사용자 지적
"게임 설정에 디폴트로 입력된 주소랑 모델명은 지워줘"

## 배경

v1.46에서 "저장 안 된 값은 회색 placeholder로만 보여주고 포커스 시
지워지게" 고쳤는데도, 회색으로나마 텍스트가 "채워져 있는 것처럼" 보여
여전히 혼동을 줄 수 있다는 재지적.

## 조치

- 저장된 값이 없으면 서버 URL/모델명 입력창을 **완전히 비워둠**(회색
  placeholder 텍스트조차 넣지 않음).
- 기본값이 무엇인지는 입력창 아래 작은 안내 라벨로만 표시:
  "(비워두면 기본값 사용: http://<내부 서버 IP>)" — 모델명 필드에도 동일한
  안내 라벨을 새로 추가(기존엔 서버 URL에만 있었음).
- 저장된 값이 있으면 정상적으로 흰 글씨로 채워지고 "✔ 저장된 값을 사용
  중입니다"로 바뀜(기존 동작 유지).
- 저장 로직도 단순화: 빈 칸이면 저장 생략(기존 값/기본값 유지), 채워져
  있으면 그대로 저장 — v1.46의 placeholder 플래그 체크가 불필요해져 제거.

## 검증

설정창을 실제로 열어 서버 URL/모델명/API Key 세 필드 모두 빈 문자열임을
확인하고, 안내 라벨 두 개가 정확한 기본값 문구를 보여주는 것도 확인. 기존
회귀 테스트(`test_gui_flow.py`, `test_progress_disconnect.py`) 재확인.
