# v1.47 — 내 메시지 시간/날짜 표시 오른쪽 정렬 (2026-09-19)

## 사용자 지적
"내가 친 채팅의 날짜가 왼쪽에 있어"

## 배경

v6.48에서 "내 메시지도 좌측 정렬로 통일(색으로만 구분)"로 바꾼 이후, 시간/
읽음 표시도 같이 왼쪽에 붙어 있었다. 확인 결과 사용자는 말풍선 자체는
좌측 정렬을 유지하되, 시간 표시만 카카오톡처럼 오른쪽에 두길 원함
(AskUserQuestion으로 확인).

## 조치

`chat_renderer.py`의 `_draw_label` — 내 메시지 분기에서 시간/읽음 라벨의
좌표를 `anchor="nw"` + `MARGIN_SIDE`(왼쪽)에서 `anchor="ne"` +
`w - MARGIN_SIDE`(오른쪽)로 변경. 말풍선 위치·색상 구분은 그대로 유지,
상대방 메시지의 이름/시간 표시는 기존 그대로 왼쪽.

## 검증

`test_gui_flow.py` 재확인(렌더링 파이프라인 정상).
