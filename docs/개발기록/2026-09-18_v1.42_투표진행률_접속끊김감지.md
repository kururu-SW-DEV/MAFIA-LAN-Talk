# v1.42 — 투표 진행률 표시 + 접속 끊김 감지 (2026-09-18)

## 사용자 지적
"투표 진행률 표시, 디스커넥트 처리 도 처리해줘"
(직전 게임 점검에서 "몇 명이 투표했는지 알 수 없다", "게임 도중 사람이
접속이 끊기거나 앱을 꺼도 아무 처리가 없다"고 지적한 항목)

## 배경 조사

- **투표 진행률**: v1.40에서 투표를 완전 익명화하고 나니, 이번엔 "몇 명이
  아직 투표를 안 했는지"조차 알 수 없어졌다 — 익명성은 지키되 진행 상황은
  보여줘야 했다.
- **접속 끊김**: 실제로 밤/투표 타이머를 다시 살펴보니, 인간 참가자 한 명이
  응답을 안 해도 기존 안전망 타이머(투표 강제개표, 밤 30초+1.5초 유예 후
  `resolve_night()`)가 이미 게임을 계속 진행시키고 있었다 — **"멈춤" 자체는
  없었다.** 진짜 빠진 건 "왜 조용한지/왜 아무도 안 죽었는지" 알려주는
  피드백이었다.

## 조치

### 투표 진행률
- `_vote_progress_counts()`/`_vote_progress_text()`/`_refresh_vote_progress_label()`
  추가 — 생존자 중 투표(votes) 또는 기권(abstains)한 인원 수만 집계, **대상은
  절대 노출 안 함**.
- 투표 팝업·재투표 팝업에 진행률 라벨(`🗳 투표 진행률 N/M`)을 추가하고, 표가
  들어올 때마다(본인·AI·재투표 전부) 즉시 갱신.
- 관련 시스템 메시지에도 "· 진행률 N/M"을 덧붙여, 팝업을 안 보는 참가자도
  진행 상황을 알 수 있게 함.

### 접속 끊김 감지
- `_mafia_poll_disconnects()` — 게임 시작 시부터 4초 간격으로, AI가 아닌
  실제 인간 참가자의 LAN 피어 `last` 타임스탬프를 `PEER_TIMEOUT`과 비교.
- 새로 끊긴 것으로 판단되면: `"⚠ {이름}님과의 연결이 끊긴 것 같습니다 —
  투표·밤 시간은 그대로 진행되며, 재접속하면 자동으로 다시 인식됩니다."`
  **역할(마피아/의사/경찰 등)은 절대 언급하지 않는 문구**로 설계 — 밤 행동이
  왜 안 일어났는지 눈치채는 방식으로 역할이 간접 노출되는 것을 방지.
- 재접속 감지 시 `"✅ {이름}님이 다시 연결되었습니다."` 안내.

### 부수 발견 (같이 수정)
투표 팝업이 0.5초 후 자동으로 닫힐 때, 1초 간격 카운트다운 타이머
(`_tick_vote`)가 취소되지 않아 이미 파괴된 라벨 위젯을 계속 갱신하려다
매초 `TclError`가 조용히 나던 기존 버그를 발견해 같이 고쳤다(`_popup_vote`
닫기 경로를 `_cancel_vote_popup()` + `_mafia_overlay_close()`로 통일).

## 검증

`tests/test_progress_disconnect.py` 신규 작성 — 두 번째 **실제** `Engine`을
인간 참가자("이팀장B")로 진짜 게임에 합류시킨 뒤:

- 유저가 투표하면 진행률 라벨이 `0/총원`에서 즉시 갱신되고, 시스템 메시지에
  "진행률 N/M"이 포함됨(대상 비노출)을 확인
- B의 엔진을 강제로 `stop()`시켜 실제 접속 끊김을 재현 → 역할 비노출 문구로
  끊김 안내가 뜨는 것을 확인
- B의 presence 타임스탬프를 갱신해 재접속을 재현 → 재접속 안내가 뜨는 것을
  확인

전체 통과. `tests/test_vote_flow.py`, `tests/test_gui_flow.py` 재실행으로
회귀 없음도 확인.
