# v5.6 좌측 사이드바 Smoothstep 슬라이딩 애니메이션 및 뷰포트 컨테이너 무왜곡 개편 (2026-09-11)

- **사이드바 접기/펼치기 애니메이션 불연속/뚝뚝 끊김 현상 근본 원인 분석**:
  - 사용자 문의: "좌측 메뉴 숨기기 애니메이션이 매끄럽지 않아. 매끄럽게 수정해줘"
  - 분석 결과:
    1) **단계 수 부족 (10스텝의 뚝뚝 끊김)**: 기존에는 총 10단계(`total_steps=10`)에 걸쳐 `cur_w`를 줄였는데, 너비 약 200px 기준 매 프레임마다 20~40px씩 급격하게 건너뛰어 시각적으로 매우 거칠고 덜컹거림 발생.
    2) **자식 위젯 충돌/찌그러짐(Layout Reflow Thrashing)**: 사이드바(`side`) 너비가 200px에서 10px로 줄어드는 동안 내부의 프로필, 탭 버튼, 검색창, 목록 헤더, 대화 행들이 강제로 축소되면서 텍스트가 줄바꿈되고 버튼들이 서로 겹치며 난잡하게 찌그러지는 현상 발생.
    3) **비대칭 가속/급정거**: 기존 `1 - (1-t)^2` 곡선은 시작 시 최대 속도로 출발하여 덜컥 시작되었고, `cur_w <= 8`에서 갑자기 잘려나가 마지막 프레임이 뚝 끊김.
    4) **불필요한 채팅 캔버스 리사이즈 타이머 반복 리셋**: 매 프레임마다 `_on_chat_resize(None)`를 호출하여 120ms 타이머를 재설정하는 불필요한 오버헤드.
- **부드러운 슬라이딩 드로어(Drawer) 아키텍처 구현**:
  - **`side_inner` 뷰포트 컨테이너 도입**:
    - `side` 내부에 고정 너비 컨테이너 `self.side_inner`를 배치하고 모든 위젯(프로필, 탭, 검색, 목록)을 `side_inner`에 패킹.
    - 애니메이션 도중 `side_inner`의 내부 레이아웃은 1픽셀도 왜곡되거나 찌그러지지 않고 100% 본래 좌표를 유지.
  - **물리적 슬라이드 아웃(Slide-Out) 클리핑 적용**:
    - 사이드바가 닫힐 때 `side_inner.place(x=cur_w - full_w)`로 설정하여 좌측 화면 밖으로 매끄럽게 밀려나며 사라지는(Slide-out) 시각적 효과 구현.
  - **타임베이스 Hermite Smoothstep Easing (`3p² - 2p³`) 적용**:
    - `duration = 0.18` (180ms), 10ms 간격 비동기 스텝.
    - 수학적으로 양 끝점(출발·도착)의 도함수(속도)가 0인 S-커브 완화 곡선을 적용하여, 출발할 때 부드럽게 가속되고 멈출 때 부드럽게 감속(Ease-In-Out)되는 네이티브급 모션 달성.
    - 타이머 기반(`time.perf_counter`)으로 프레임 드랍이 발생해도 정확한 시간에 오차 없이 도착.
  - **완료 시점에만 대화창 최종 정렬 (`_reload_chat(..., from_cache=True)`)**:
    - 애니메이션 진행 중에는 캔버스가 부드럽게 확장되기만 하고, 애니메이션이 완전히 끝난 순간 O(1) 메모리 캐시를 통해 말풍선 좌표를 1회만 완벽 정렬.
