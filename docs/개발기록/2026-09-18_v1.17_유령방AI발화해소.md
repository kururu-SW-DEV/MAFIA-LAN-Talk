# v1.17 — 유령방 AI 발화 무음 소멸 해소 (2026-09-18)

## 사용자 지적
"유령방에서 AI가 챗을 안하는 이유가 뭐야"

## 원인 (실측 확정) — 2중

1. **진원지: 백그라운드 워커 스레드가 `root.after(0, ...)` 직접 호출**
   Tk는 메인스레드 전용 — 워커 스레드에서 after 호출이
   `RuntimeError: main thread is not in main loop` → 함수 상단의
   `except: pass`가 오류를 **무음 소멸** → AI 수다가 화면에 한 번도 안 뜸.
   (이전 E2E 디버그에서 정확히 이 오류 관측)
2. **2차 결함: overlay_prev_close가 폴러 플래그 리셋**
   `_mafia_overlay_open`이 기존 overlay를 먼저 닫으며 `_ghost_ui_open=False`
   리셋 → 유령방 UI 큐 폴러가 300ms 후 재예약을 안 함 → 큐에 담긴
   AI 발화가 드레인되지 않음.

## 조치 (v1.17)

| 항목 | 내용 |
|---|---|
| 스레드 분리 | LLM 호출만 워커 스레드, UI 반영은 `queue.Queue` → 메인스레드 폴러(300ms) |
| 폴러 생명 | `_ghost_ui_open` 플래그 — 유령방 열림 시 True, 닫힘 시 False |

| 임시 문구 | LLM 실패 시 3~5초 후 기본 유령 수다 유지(v1.13 그대로) |
