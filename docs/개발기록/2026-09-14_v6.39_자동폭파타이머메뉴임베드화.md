# v6.39 — 자동 폭파(⏱) 타이머 메뉴 임베드화 (2026-09-14)

## 계기

v6.38에서 채팅·친구 목록 우클릭 메뉴, 이름 변경/내 IP/별칭 모달을
"본창 안쪽에 뜨는 임베드 방식"으로 바꿨는데, 채팅 입력창 옆의 ⏱(자동
폭파 타이머) 버튼을 누르면 나오는 메뉴는 그때 빠뜨렸다. 이어서 마저
전환했다.

## 수정한 항목

- **⏱ 자동 폭파 타이머 메뉴** (`app.py` `_open_burn_menu`): 별도 Toplevel
  대신 `_popup_menu(..., embed=True)`로 전환. 이 버튼은 채팅 입력창(본창의
  일부)에 있어, 다른 다이얼로그 안에 있는 게 아니라 임베드 방식(본창
  `self.root` 기준으로 위치를 잡는 방식)을 그대로 써도 안전하다.

## 검증

- `python -m py_compile app.py` 통과.

## 남은 항목

- `dialogs.py`의 프로필 사진 메뉴(`_open_my_avatar_menu`)도 본창 기준이라
  같은 방식으로 전환 가능하지만 이번 회차 요청 범위 밖이라 보류.
- `_broadcast_dialog` 안의 자동 삭제 타이머 메뉴(`_open_broadcast_burn_menu`)는
  다른 Toplevel 다이얼로그 **안에서** 열리는 메뉴라 임베드 대상에서
  제외 — 임베드는 본창 기준으로 뜨기 때문에 다른 Toplevel 위에서 열면
  그 뒤에 가려 보이지 않는다.
