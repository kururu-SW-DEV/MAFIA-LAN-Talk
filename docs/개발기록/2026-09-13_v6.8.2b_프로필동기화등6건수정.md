# v6.8.2 — 프로필 동기화·ICMP 로그·그룹 재초대 등 6대 결함 정밀 수정 (2026-09-13)

> 참고: 이 항목은 원본 개발기록.md에서도 "v6.8.2"라는 같은 버전 번호를 [`2026-09-13_v6.8.2_DPI비인식버그.md`](2026-09-13_v6.8.2_DPI비인식버그.md)와 중복해서 쓰고 있었다(다른 세션이 각자 독립적으로 v6.8.2를 적은 것으로 추정). 내용을 소급 수정하지 않고 원문 그대로 옮기되, 파일명으로 구분해뒀다.

### 1. 프로필 사진(아바타) 동기화 패킷 UnboundLocalError 수정 (`engine.py`)
- **결함 원인**: `_handle()`의 `avatar_req`, `avatar_resp`, `avatar_update` 패킷 브랜치에서 `ip = addr[0]` 할당문이 누락되어, 블록 내 `self._send_dict(resp, ip, sport)` 및 `(ip, sport) in self.peers` 접근 시 `UnboundLocalError`가 발생하고 프로필 사진 네트워크 전파가 100% 마비되던 결함.
- **해결책**: `_handle()` 최상단 공통 영역에서 `ip = addr[0]`를 1회 안전하게 바인딩하여 모든 패킷 핸들러가 `ip`를 안정적으로 참조하도록 보장.

### 2. SIO_UDP_CONNRESET 네이티브 호출 및 WinError 10054 로그 폭풍 차단 (`engine.py`)
- **결함 원인**: 파이썬 표준 `socket` 모듈에 없는 `socket.SIO_UDP_CONNRESET` 호출이 무력화되어, 오프라인 동료에 대한 UDP 패킷 전송 시 반환되는 ICMP Port Unreachable로 인해 `_recv_loop`에서 `ConnectionResetError: [WinError 10054]`가 초당 수십~수백 회씩 `debug.log`에 폭풍 기록되던 문제.
- **해결책**: Windows 환경에서 `ctypes.windll.ws2_32.WSAIoctl(self.sock.fileno(), 0x9800000C, ...)`을 직접 호출하여 소켓 리셋을 원천 비활성화하고, `_recv_loop`의 `except OSError`에서도 10054 예외를 로깅 없이 조용히 무시(`continue`)하도록 방어.

### 3. 그룹 탈퇴 멤버 재초대(Re-invite) 시 3자 로스터 영구 누락 결함 해결 (`engine.py`)
- **결함 원인**: 그룹 탈퇴 시 등록된 `g["left"]` 묘비(Tombstone) 집합이, 다른 멤버가 해당 탈퇴자를 정식으로 재초대(`add_group_members`)하여 `group_invite`를 전파했을 때 제3자 동료들의 `g["left"]`에서 지워지지 않아 `effective = members - left`에 의해 영구 필터링되던 결함.
- **해결책**: `group_invite` 수신 시 초대장에 실려온 최신 멤버 목록에 대해 `g.setdefault("left", set()).difference_update(members)`를 수행하여, 정식 재초대된 멤버가 제3자의 `left` 목록에서 해제되고 정상 합류되도록 수정.

### 4. 메시지 전송(ACK), 읽음 확인(read_ack), 창 리사이즈 시 화면 깜빡임 및 스크롤 하단 튐 방지 (`app.py`)
- **결함 원인**:
  1. `_on_sent`에서 이미 렌더링된 말풍선을 두고 `_reload_chat(self.current)`을 다시 호출하여 전체 캔버스를 파괴하고 다시 그리던 불필요한 깜빡임 발생.
  2. `_reload_chat`이 무조건 `self._finish_render(force_bottom=True)`를 실행하여, 과거 대화를 스크롤해서 읽고 있던 도중 상대의 `read_ack` 도착이나 창 리사이즈 발생 시 화면이 강제로 맨 아래로 튀어버리던 UX 결함.
- **해결책**:
  1. `_on_sent`의 불필요한 `_reload_chat` 호출을 제거하고 상태바만 갱신.
  2. `_reload_chat`에 스크롤 위치 보존 로직을 도입하여, 방을 새로 여는 `_select` 외의 상황(`read_ack`, 창 리사이즈 등)에서는 기존 `yview()` 위치(`saved_top`)를 복원하여 스크롤 튐을 원천 방지.

### 5. 멤버 목록 및 친구 선택 모달 대화상자 마우스 휠 스크롤 미작동 해결 (`app.py`)
- **결함 원인**: `_open_member_dialog` 및 `_build_picker_list`에서 마우스 휠 이벤트가 `Canvas`에만 바인딩되어, 마우스 커서가 내부의 프레임·라벨·아바타 등 자식 위젯 위에 올라가면 이벤트가 전파되지 않아 휠 스크롤이 먹통이 되던 문제.
- **해결책**: 리스트 컨테이너 프레임에 `<Enter>` / `<Leave>` 기반 `bind_all("<MouseWheel>")` 이벤트 라우팅을 등록하고, 창 닫힘(`<Destroy>`) 시 안전하게 해제하도록 개선.

### 6. 전체 대화 검색(search_all_logs) 인덱스 정합성 교정 (`engine.py`)
- **결함 원인**: `search_all_logs`가 텍스트 파일의 원시 줄 번호(`enumerate(f)`)를 `rec_idx`로 반환하여, 빈 줄이나 유효하지 않은 행이 있는 경우 `load_history`가 파싱한 레코드 인덱스와 어긋나 검색 결과 클릭 시 엉뚱한 위치로 스크롤되던 문제.
- **해결책**: `load_history`와 동일한 조건(`isinstance(r, dict) and ("text" in r or "kind" in r)`)을 만족하는 유효 레코드만 `rec_idx`로 카운트하여 캔버스 상의 y좌표와 1:1 완벽 일치하도록 교정.
