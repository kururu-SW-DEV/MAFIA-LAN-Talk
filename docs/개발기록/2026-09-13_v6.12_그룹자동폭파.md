# v6.12 그룹 대화방 자동 폭파(Self-Destruct) 메시지 확장 — 발신 시점 기준 일괄 삭제 (2026-09-13)

- **계기**: v6.11에서 1:1 대화방에 자동 폭파 타이머를 도입한 후, 사용자가 그룹 대화방에서도 동일하게 비밀 메시지 폭파 기능을 사용하길 원함.
- **방식 결정 (Option 2 선택)**:
  - 1:1 대화는 상대방이 메시지를 읽는 시점(`read_ack`)부터 카운트다운을 시작하는 것이 자연스러움.
  - 하지만 그룹 대화는 멤버가 여럿이어서 각자 읽는 시각이 제각각임(누구는 1분 뒤, 누구는 1시간 뒤).
  - 따라서 그룹 대화는 **"발신 시점 기준 일괄 삭제(Send-Time Expiry)"** 방식을 채택: 메시지가 발송된 순간부터 카운트다운(30초, 5분, 1시간, 24시간)이 시작되어 지정 시간이 경과하면 모든 그룹원의 PC에서 동시에 일괄 영구 소멸됨.
- **네트워크 및 영속 계층 (`engine.py`)**:
  - `send_group_message(gid, text, reply=None, burn_sec=0)`: `burn_sec` 매개변수 추가, `burn_deadline = time.time() + burn_sec` 계산.
  - 패킷에 `"burn_sec"` 및 `"burn_deadline"`을 실어 브로드캐스트.
  - 발신자 및 수신자 모두 `_append_group_log`에서 `burn_sec`와 `burn_deadline`을 기록하고, `_burn_candidates` 집합에 `("grp", gid)` 등록.
  - 만료 시 기존 `_sweep_burns`가 `("grp", gid)` 로그 파일에서 만료된 레코드를 영구 파기하고 원자적 파일 재작성 후 `{"ev": "burned", "key": ("grp", gid)}` 이벤트 발행.
  - **신규 멤버 초대 보안 강화 (`_recent_group_history`)**: 그룹 중간에 새 멤버가 초대되어 최근 대화 50건 스냅샷이 전달될 때, 폭파 타이머가 걸린 비밀 메시지는 원천 배제(`not r.get("burn_sec")`)하여 새 멤버에게 비밀이 누출되는 보안 사고를 방지.
- **UI 계층 (`app.py`)**:
  - `_select()`: 그룹방 선택 시에도 `burn_btn`이 `normal`로 활성화 유지되며, 방별 폭파 타이머 설정에 맞춰 점등(`_sync_burn_btn_visual()`).
  - `_open_burn_menu()`, `_set_burn_mode()`: 그룹방에서도 팝업 메뉴 정상 표시 (24시간 옵션 포함). 그룹방일 때 "이 그룹방에서 보낼 메시지는 전송 후 N 뒤 자동 삭제됩니다" 맞춤 안내 표시.
  - `_send()`: 그룹 메시지 전송 시 방의 `_burn_mode` 값을 조회해 `send_group_message(..., burn_sec=burn_sec)`로 전달하고, 내 화면 말풍선에 `🔥{시간}` 및 `unread_count` 즉시 렌더링.
  - `_on_gmsg()`, `_rec_from_raw()`: 그룹 메시지 수신 시 말풍선에 `burn_sec` 배지 정상 표시.
  - `burned` 이벤트 수신 시 그룹방에서도 실시간으로 채팅 캔버스를 새로고침하여 만료된 메시지 즉시 소멸.
- **검증**:
