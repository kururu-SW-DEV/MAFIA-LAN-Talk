# v1.11 — 죽은 AI가 다음 턴에 말하는 결함 해소 (2026-09-18)

## 사용자 지적
"저번턴에 죽은 AI 봇이나 사람이 왜 다음턴에서는 말할수 있는거야?"

## 원인 (실측 확정)

**core와 AI 개체의 alive 상태가 동기화되지 않았음**

- core.players[X]["alive"] = False만 세팅되고(처형/밤사망),
- `PlayerAgent.alive`는 계속 True로 남아
- `AIDirector.say_async()`가 `pl.alive`로 필터하기 때문에 **죽은 AI도 살아있는
  것처럼 계속 발화**했습니다.

(AI 사망 게이트 자체는 원래 존재했지만 — core에만 반영되고 AI 개체에 전달되지
않은 '단순 누락'이었습니다.)

## 조치 (v1.11)

`_sync_ai_alive()` 헬퍼 신설 — core.alive_players() 기준으로 PlayerAgent.alive
동기화. 사망이 확정되는 3개 지점에 모두 삽입:

| 지점 | 내용 |
|---|---|
| 낮 처형 | `_tally_and_reveal` → execute 후 |
| 최후 변론 처형 | `_resolve_defense` → execute_defense 후 |
| 밤 사망 | `_after_night` 진입 즉시 |

## 실측

```
지은 처형 → core.alive_players() = [정민호, 김과장, 현우]
→ pl.alive = {'지은': False} (동기화 정상)
→ 다음 턴 say_async 참여자 = ['김과장', '현우'] — 죽은 지은 제외 확인
```

사람 사망자는 기존 게이트(사망자 채팅 차단 + 유령방 안내)로 이미 차단됨.
