# v5.3 다크 타이틀바 DWM 안착, 아바타/나 배지 기반 그룹 멤버 목록 개편, 친구 체크리스트 + 직접 IP 초대 지원 (2026-09-11)

- **다이얼로그 창 타이틀바 다크 테마 완전 일치 (`apply_dark_titlebar`)**:
  - 사용자 문의: "이 창 상단이 너무 하얀색 같지?"
  - 원인 분석: Tkinter `Toplevel` 다이얼로그 창이 `transient(root)` 및 화면 매핑을 거치면서 Windows 내부에서 외부 프레임 HWND가 재생성되어 초기 DWM 설정이 흰색 기본값으로 리셋되던 문제.
  - 개선: `apply_dark_titlebar`에서 `win.winfo_id()`뿐만 아니라 `GetParent(hwnd)`를 탐색하여 최상위 프레임 둘 다에 DWM 다크 모드 속성(`DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWA_CAPTION_COLOR`, `DWMWA_TEXT_COLOR`)을 적용하고, `after(30)` 및 `after(120)` 비동기 재적용 파이프라인을 추가하여 창이 뜬 후에도 완벽한 다크 티타늄 타이틀바 유지.
- **아바타 및 '나' 배지 기반 그룹 멤버 목록 전면 개편 (`_open_member_dialog`)**:
  - 사용자 문의: "목록이 아이피 기반이니 누가 누구인지 모르겠어. 누군지 알아볼수 있게 상대방 이름이 나오는 목록 리스트로 해야지."
  - 기존 문제: 멤버 창에 단순 텍스트 레이블로 `127.0.0.1 (127.0.0.1:60001)`처럼 IP만 나열되었고, '나'는 멤버 수 및 목록에서 완전히 누락되어 있었음.
  - 개선:
    1) 상단에 전체 참여 멤버 수 (`1(나) + 동료 수`) 및 그룹 이름 헤더, 우측 상단에 빠른 `[＋ 멤버 추가]` 버튼 배치.
    2) 맨 첫 번째 행에 **'나' (Me)** 항목을 배치하여 내 아바타, 이니셜, 온라인 초록불, 이름, `[나]` 티타늄 블루 배지, 내 연결 포트 및 '방 참여 중' 안내 제공.
    3) 모든 동료 멤버 행에 **원형 컬러 아바타**, **실시간 온라인 상태 점**, **식별 가능한 이름(별칭 > 네트워크 등록 이름 > IP 순)** 렌더링. 별칭이 지정된 경우 원래 이름 `(원래이름)`을 나란히 병기.
    4) 각 동료 행 우측에 **`[1:1]` 즉시 대화 버튼**(클릭 시 해당 동료와의 1:1 대화방으로 즉시 이동) 및 **`[별칭]` 이름 변경 버튼**(클릭 시 별칭 변경 다이얼로그가 열리고 즉시 멤버 목록에 실시간 반영) 추가.
    5) P2P 네트워크 계층에서 `group_invite` 및 `group_msg` 수신 시 발신자 및 패킷 내 동료 이름을 `_upsert_peer`로 자동 학습·동기화하도록 개선.
- **친구 체크리스트 + 직접 IP 입력 초대 듀얼 모드 (`_group_add_member_dialog`)**:
  - 사용자 문의: "그리고 맴버추가 기능은 친구추가 같이 목록 리스트 맞지?"
  - 개선:
    1) 친구 탭과 동일하게 **아바타, 이름, 온라인 점, 체크박스**로 구성된 다중 선택 피커 리스트 제공.
    2) 아직 친구 목록에 등록되지 않은 동료도 바로 초대할 수 있도록 하단에 **"직접 IP:포트 입력 초대"** 입력란(`예: 192.168.0.15:50707`) 신설.
    3) 친구 목록에 상대가 없는 상태라도 안내 메시지와 함께 직접 IP 입력을 통해 즉시 초대가 가능하도록 차단 없는 UX 구현.
    4) 초대 완료 시 사이드바 및 열려 있는 멤버 목록 창이 실시간 자동 갱신됨.
