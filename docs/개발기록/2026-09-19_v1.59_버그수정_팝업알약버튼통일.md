## 1. 발견된 버그 및 수정 내용

| 버그 구분 | 원인 및 현상 | 조치 내용 |
|---|---|---|
| **`emoji_render.py` cget("text") 빈 문자열 반환 버그** | `enable_color_emoji` / `enable_pill_button` 적용 시 이미지 합성을 위해 Tkinter 위젯 text를 `""`로 비우고 있었으나, `cget`과 `__getitem__`이 래핑되지 않아 `widget.cget("text")` 또는 `widget["text"]` 조회 시 항상 `""`가 반환됨. 이로 인해 `test_progress_disconnect.py` 진행률 검증이 15초간 멈추고 크래시 발생. | `enable_color_emoji` 및 `enable_pill_button`에서 `cget`과 동적 서브클래스(`__getitem__`)를 래핑하여 논리적 텍스트(`text`), 상태(`state`), 커맨드(`command`)를 온전히 반환하도록 수정. |
| **투표/재투표 팝업 연타(Double-click) 버그** | 유저가 투표 버튼 클릭 시 클릭된 1개 버튼만 disabled되고, 0.5초 피드백 지연 동안 다른 후보 버튼들과 기권 버튼은 계속 활성 상태라 빠른 연타 시 중복 호출 위험. | `_popup_vote` 및 `_cast_revote`에서 투표/기권 클릭 즉시 모든 후보 버튼 및 기권 버튼을 비활성화(`state="disabled"`) 처리하고, 선택된 버튼에만 `✓ {name}` 시각 피드백 부여. |
| **disabled 버튼 마우스 오버 시 호버 색상 번쩍임 결함** | `dialogs.py`의 `_hover` 및 인라인 버튼 이벤트에서 `state == "disabled"` 검사 없이 `<Enter>` 시 `bg=hover`로 강제 변경되어, 비활성화된 회색 버튼에 마우스를 올리면 활성 호버 색으로 깜빡임. | `_hover` 및 `enable_pill_button` 호버 핸들러에 `state != "disabled"` 가드를 적용하여 비활성 버튼은 마우스 오버 시 색상이 변하지 않도록 차단. |

## 2. 팝업 알약형(둥근 모서리) 버튼 UI 통일 (사용자 요청)

상단 마피아 바와 대화 말풍선은 둥근 모서리(radius 10~14px)인 반면, 팝업들의 버튼은 0px 각진 기본 사각형(`relief="flat"`)으로 렌더링되던 불일치를 전면 개선했습니다.

1. **`emoji_render.py` 기능 확장**:
   - `render_pill(..., min_w=None)`: 버튼 최소 너비(`min_w`) 및 텍스트 중앙 정렬 지원(그리드 내 후보 버튼 너비 일치).
   - `make_pill_button(parent, text, cmd, bg, fg, hover_bg, ...)`: 팝업 어디서든 한 줄로 둥근 모서리 알약 버튼(호버 및 disabled 가드 포함)을 생성하는 팩토리 함수 신설.
2. **투표 팝업 (`_show_vote_popup`)**:
   - 3열 그리드 생존 후보 버튼들을 둥근 모서리 알약 버튼(`radius=8`, `min_w=96`, 호버 효과)으로 교체.
   - 하단 기권 버튼을 둥근 알약 버튼(`radius=6`)으로 교체.
3. **재투표 팝업 (`_show_revote_popup`)**:
   - 동률 후보 버튼 및 기권 버튼을 둥근 모서리 알약 버튼으로 교체.
4. **최후변론 찬반 팝업 (`_show_defense_vote_popup`)**:
   - `🔪 처형 찬성` (레드 알약 버튼, `radius=8`, `hover_bg="#ef4444"`)
   - `🕊 만류` (그린 알약 버튼, `radius=8`, `hover_bg="#16a34a"`)
   - 피고인 본인 화면의 `확인 (닫기)` 버튼 (다크 알약 버튼, `radius=6`)
5. **밤 행동 팝업 (`_show_night_panel`)**:
   - 경찰 조사 대상 후보 버튼들 (알약 버튼, `radius=8`, `min_w=90`)
   - 마피아 살해 / 의사 구조 대상 후보 버튼들 (알약 버튼, `radius=8`, `min_w=90`)
6. **직업 확인 팝업 (`_show_role_popup`)**:
   - `확인 (비밀 유지)` 버튼을 역할 테마색 둥근 알약 버튼(`radius=8`)으로 교체.
7. **게임 설정 팝업 (`mafia_settings_dialog`)**:
   - 하단 `저장`, `취소` 버튼을 둥근 알약 버튼(`radius=6`)으로 교체.
