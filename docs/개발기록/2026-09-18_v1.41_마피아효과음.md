# v1.41 — 마피아 게임 전용 효과음 추가 (2026-09-18)

## 사용자 지적
"효과음부터 추가해줘" (게임 진행방식·UI·효과음·로비 등 종합 점검 요청에서
효과음을 최우선으로 선택)

## 배경

`_play_mafia_sound`가 실제 사운드 파일 없이 전부 `winsound.MessageBeep`/
`Beep` 같은 윈도우 시스템 비프음이었다. 밤이 찾아올 때·처형될 때·무죄로
풀릴 때가 다 그냥 "삑" 소리라 서스펜스가 살지 않았고, **게임 종료(승/패)
시점에는 사운드가 아예 없었다.**

## 조치

외부 에셋·인터넷 없이 순수 stdlib(`wave`+`math`)로 8개 WAV를 직접 합성해
`sounds/`에 저장하고 연결했다.

| 파일 | 용도 |
|---|---|
| `night.wav` | 밤이 찾아올 때 — 낮게 가라앉는 음산한 2음 |
| `day.wav` | 아침이 밝을 때 — 밝게 올라가는 3음 아르페지오 |
| `trial.wav` | 재판 개시 — 낮은 "쿵"(의사봉) 임팩트 |
| `guilty.wav` | 유죄 처형 — 어둡게 떨어지는 스팅어 |
| `innocent.wav` | 무죄 방면 — 청량한 벨 2음 |
| `tick.wav` | 최후 변론 카운트다운 10초 전부터 매초 초읽기음 |
| `citizen_win.wav` / `mafia_win.wav` | 승패 팡파르 (신규 — 기존엔 게임 종료 사운드 자체가 없었음) |

- `mafia_ui.py`의 `_play_mafia_sound`가 `sounds/*.wav`를 `winsound.PlaySound`
  (비동기)로 재생하도록 변경. **파일이 없거나 재생 실패 시에만** 기존 비프로
  자동 폴백(하위 호환·안전망 유지).
- `_on_game_end`에 승/패 사운드를 새로 연결.
- exe 빌드 시에도 포함되도록 `MAFIA.spec`의 `datas`와 `build_exe.py`의
  PyInstaller `--add-data`에 `sounds/` 번들 설정 추가.
- 리소스 경로는 `netutils.resource_dir()`을 그대로 재사용(개발 실행/온파일
  exe 양쪽 다 동작, `app.ico`와 동일한 패턴).
