# v1.33 — 최후변론 찬반 개표 이중 출력 제거 (2026-09-18)

## 사용자 지적
"최후변혼 찬반여부가 두번나와"

## 원인 (E2E 재현 확정)

찬반 개표 트리거(`_maybe_resolve_defense`)가 두 곳에서 0.3초 뒤
`_resolve_defense`를 예약 — 유저 클릭 1회 + AI 마지막 표 접수 1회가
겹치면 **개표가 2회 실행**:
- 1회째: "⚖ 찬성 3 : 반대 0 — 처형 확정" (정상)
- 2회째: 찬반 표 저장소가 이미 클리어된 상태로 재개표 → "⚖ 찬성 0 : 반대 0 — 처형 부결" 출력
→ 찬반 여부가 두 번 뜨고, 2번째는 엉뚱한 '부결'이라 결과 부신감.
