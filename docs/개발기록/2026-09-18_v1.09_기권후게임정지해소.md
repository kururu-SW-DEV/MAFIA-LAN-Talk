# v1.09 — 유저 기권 후 게임 정지 해소 (2026-09-18)

## 사용자 지적
"내가 기권처리 하니 게임이 진행이 안되네"

## 원인 (실측 확정)

1. **core.cast_abstain이 DAY phase만 허용** — 투표 팝업이 뜨면 phase가 이미
   VOTE였고, 이때 유저가 기권하면 `cast_abstain()`이 조용히 False를 반환해
   **기권이 접수되지 않았음**.
2. **core.all_voted()가 기권을 무시** — votes에만 보는 조건이라 유저가 기권하면
   `all_voted()`가 영원히 False → 조기 개표 트리거가 발동하지 않음 →
   120초 낮 타이머가 다 흐를 때까지 아무 일도 안 일어남(= "진행 안 됨").
3. **1차 투표 팝업에 기권 버튼이 없었음** — 재투표 팝업에만 기권이 있었음.

## 조치 (v1.09)

| 항목 | 내용 |
|---|---|
| cast_abstain 허용 범위 | DAY·VOTE 둘 다 허용 — 팝업 기권이 반드시 접수됨 |
| all_voted | votes 또는 abstains — 기권자도 '접수 완료'로 인정 |
| 기권 버튼 | 1차 투표 팝업 하단에 기권 버튼 추가(`_popup_vote(None)`) |
| _popup_vote(None) | 기권 접수 시 말풍선+시스템 문구 출력 |
