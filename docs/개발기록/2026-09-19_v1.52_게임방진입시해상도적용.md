# v1.52 — 게임방 진입 시점부터 1400x800 적용 (2026-09-19)

## 사용자 지적
"시작할때 해상도가 1400 x800 이 아니야 기존 해상도로 나와"

## 원인

v1.50에서 추가한 해상도 조정이 "게임 시작" 버튼(`_launch_game_with_recruits`)
시점에만 걸려 있었다. 마피아 게임방에 들어가긴 했지만 아직 "게임 시작"을
누르기 전(로비/모집 상태)에는 여전히 기존 450x800 그대로였다.

## 조치

`_select_mafia_room`(사이드바에서 마피아 게임방을 클릭해 들어가는 시점)에
`_mafia_maximize_window()` 호출을 추가 — 세션당 한 번만 자동 적용되도록
`_mafia_resized_once` 플래그로 가드(이후 사용자가 직접 창 크기를 조절해도
방을 왔다갔다 할 때마다 강제로 되돌리지 않음). 게임 시작 시점 호출도 그대로
유지(어느 경로로 들어와도 확실히 적용).

## 검증

"방 진입 전 450x800 → 방 진입 후(게임 시작 전) 1400x800" 전환을 헤드리스로
재현해 확인. 기존 회귀 테스트 재확인.
