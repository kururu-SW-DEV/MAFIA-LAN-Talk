# v1.37 — 마피아 로비 게임 시작 전 인간 참가자 단체 대화 활성화 (2026-09-18)

## 1. 개요 및 배경
- **현상**: 기존에는 게임 시작 전(`not self.mafia_active`)에 채팅을 입력하면 "게임이 아직 시작되지 않았습니다. [게임 시작]을 눌러 주세요." 라며 입력을 전면 차단하여, 로비나 참가자 모집 중에 실제 인간들끼리 시작 전 소통(인원 조율, 시작 요청, 잡담 등)이 불가능했음.
- **개선 목표**:
  - 게임 시작 전 로비(모집 중 포함)에서 실제 접속 중인 인간 참가자들끼리 자유롭게 단체 P2P 채팅을 나눌 수 있도록 개선.
  - 게임이 시작되면 자연스럽게 사회자 개회 및 마피아 추리 모드로 전환.

## 2. 주요 변경 내역
1. **로비 단체 채팅 프로토콜 추가** (`mafia_net.py`)
   - `EVENT_LOBBY_CHAT = "lobby_chat"` 이벤트 상수 정의.
2. **로비 채팅 입력 허용 및 브로드캐스트** (`mafia_ui.py`)
   - `_mafia_handle_user_text`에서 `not self.mafia_active` 상태일 때 입력 차단 안내를 제거하고, 내 화면에 말풍선 출력 후 `_mafia_broadcast("lobby_chat", sender=me, text=text)` 전송.
   - 명령어(`/참가`, `/취소`)는 우선 처리 유지.
3. **로비 채팅 수신 핸들러 추가** (`mafia_ui.py`)
   - `_on_mafia_proto_msg`에 `lobby_chat` 이벤트 수신 처리 추가 (`self.add_mafia_bubble(msg_text, sender)`).
