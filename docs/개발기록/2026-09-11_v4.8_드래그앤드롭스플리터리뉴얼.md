# v4.8 스플릿 바 핸들 리뉴얼 & 전 위젯 드래그 앤 드롭 파일 전송 & [첨부] 텍스트 버튼 개편 (2026-09-11)

- **채팅창 및 전 윈도우 파일 드래그 앤 드롭(Drag & Drop) 네이티브 전송 완벽 해결**:
  - 기존 문제: 초기 구현 시 윈도우가 화면에 표시되기 전(`update_idletasks` 이전) 호출되어 임시 핸들에 등록되었고, 대화창 캔버스·입력창 등 실제 마우스가 위치하는 자식 위젯(`TkChild`)들이 `DragAcceptFiles` 등록 및 서브클래싱에서 누락되어 Windows에서 금지 표시(🚫)가 뜨며 드롭이 동작하지 않던 문제 해결.
  - 개선:
    1) Windows Shell API(`shell32.DragAcceptFiles`, `shell32.DragQueryFileW`, `shell32.DragFinish`)를 최상위 프레임뿐 아니라 대화창 캔버스(`canvas`), 텍스트 입력창(`entry`), 사이드바 등 모든 자식 위젯에 재귀적으로 일괄 등록(`hook_tree`).
    2) `WM_DROPFILES (0x0233)`를 가로채는 서브클래싱 `WndProc`을 모든 자식 위젯에 적용하여, 창 어느 곳에 파일을 끌어다 놓아도 100% 즉시 수신 및 전송 파이프라인(`_send_file_path`) 실행.
    3) Windows UIPI(사용자 인터페이스 권한 격리) 필터(`ChangeWindowMessageFilter`, `ChangeWindowMessageFilterEx`)를 등록하여 탐색기 권한 차단 문제 방어.
    4) `<Map>` 이벤트 및 `after(100)`를 통해 창 매핑 시점의 실제 HWND를 보장하며, 앱 종료 시(`_quit`) 등록된 모든 윈도우 프로시저를 안전하게 복원(`_dnd_hooked`).
- **스플릿 바 숨기기 버튼 디자인 모던 슬림 리뉴얼 & 사이드바 헤더 토글 버튼 추가**:
  - 기존 문제: Tkinter Canvas의 `smooth=True` 폴리곤 보간으로 인해 모서리가 왜곡된 감자 모양으로 뭉개지고 폰트 글리프가 흐릿하게 렌더링되던 문제.
  - 개선:
    1) 기하학적 4코너 아크와 직사각형 결합으로 왜곡 없는 깨끗한 둥근 캡슐(`w=18, h=44, r=4`) 위젯 `SplitterHandle` 재설계.
    2) 폰트 의존성 없는 선명한 2px 벡터 셰브론(`<` / `>`) 라인을 중앙에 렌더링하여 모던 IDE(VS Code/JetBrains) 스타일의 미니멀 룩 완성.
    3) 사이드바 상단 헤더(`hrow`)에도 직관적인 접기/펼치기 버튼(`self.side_toggle_btn`, `[◀]`)을 신설하여, 스플리터 기둥뿐 아니라 헤더에서도 즉시 사이드바를 원클릭 토글할 수 있도록 편의성 대폭 향상.
- **첨부파일 버튼 [첨부] 텍스트 버튼으로 전면 개편**:
  - 기존 문제: 맑은 고딕 글꼴의 클립 이모지나 작은 아이콘이 다크 테마에서 시인성이 떨어지던 문제.
  - 개선: 아이콘 대신 시인성이 100% 보장되는 선명한 볼드 화이트 텍스트 버튼(`"첨부"`, `FONT_BTN`, `C_CARD` 배경, 호버 하이라이트)으로 전면 교체.
  - 우측 `[전송]` 버튼과 완벽하게 대칭되는 균형 잡힌 레이아웃을 형성하며, 360px 이하의 극소 화면에서도 텍스트 입력창 너비가 충분히 확보되도록 버튼 패딩과 반응형 비율 최적화.
- 검증: `test_new_features.py`(전 위젯 DND 훅 등록, [첨부] 텍스트 버튼, 스플리터 핸들, 작은 창 반응성 단위 검증), `smoke_gui.py`, `test_headless.py`, `test_gui_flow.py` 전 테스트 통과.
