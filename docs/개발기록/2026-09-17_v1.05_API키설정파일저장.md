# v1.05 — AI API 키 설정 파일 저장 (재시작 유지) (2026-09-17)

## 사용자 요청
"내가 API키를 입력하면 프로그램에 저장되게 해줘"

## 이전 동작
⚙ 설정 → AI API 섹션에서 [저장] 누르면 `RUNTIME_OVERRIDES`(메모리)에만 담김 —
**프로그램 재시작하면 사라져서 매번 다시 입력해야 했음.**

## 수정

| 단계 | 내용 |
|---|---|
| 저장 위치 | `<데이터 폴더>/mafia_llm.json` — 랜톡의 datadir(포터블 구조) 기준 |
| 저장 내용 | `{"api_key": "...", "base_url": "...", "model": "..."}` |
| 저장 트리거 | ⚙ 설정 → AI API → [저장] 클릭 시 `mafia_config.save_overrides()` |
| 로드 트리거 | 앱 기동 시 `mafia_ready()` → `load_overrides()` — 설정창/LLM 호출에 자동 반영 |
| 우선순위 | 환경변수(MAFIA_LLM_API_KEY) > 파일 저장 > 기본값 |

## 실측 (통과)

```
save_overrides: True
file exists: True
after restart:
  loaded overrides: {'base_url': 'http://<내부 서버 IP>',
                     'model': 'Qwen/Qwen3.8-27B',
                     'api_key': '***'}
  file content keys: ['api_key', 'base_url', 'model']
```
키·URL·모델 모두 파일에서 재시작 후에 로드 확인.

## LLM 호출 반영
`_llm_call`에서 세션 중 `RUNTIME_OVERRIDES`가 비었을 때 파일을 즉시 로드 —
재시작 직후 첫 AI 발화부터 저장된 키·URL·모델 사용.

## 배포
- 전체 컴파일 ALL OK → exe 재빌드(30.770MB) → Desktop 재배포 완료

**주의**: `mafia_llm.json`은 일반 텍스트에 키 유지 — 스티커·기록 등 다른 파일과
달리 **설정 상태 파일로 외부 공유 금지.** 사내 배포는 각자 PC에서 자기 키를 설정.
