# v1.46 — AI API 설정창 서버 URL/모델 기본값 오인 방지 (2026-09-19)

## 사용자 지적
"여기에 디폴트로 입력되어 있는 서버 값 때문에 나중에 값을 변경해도 항상
디폴트 값인거 처럼 보여 수정해줘" (마피아 게임 설정 화면 스크린샷 첨부)

## 원인

서버 URL/모델명 입력창이 저장된 값이 없어도 기본값을 흰 글씨로 그대로
채워 넣고 있었다. 값을 바꿔서 저장해도 다음에 열었을 때 "이게 내가 저장한
값인지 그냥 기본값인지" 구분할 방법이 없었고, 안 건드리고 그냥 저장해도
화면에 있던 기본값 텍스트가 그대로 실제 설정값으로 저장돼버렸다.

## 조치

- 저장된 값이 없을 때만 기본값을 회색 글씨(placeholder)로 보여주고, 클릭하면
  자동으로 지워짐(API Key 필드의 마스킹 방식과 동일 패턴).
- 실제로 저장된 값이 있으면 흰 글씨로 표시 + "✔ 저장된 값을 사용 중입니다"
  / "(현재 기본값: ...)" 안내 라벨 추가.
- placeholder 상태(안 건드림)로 저장을 눌러도 오버라이드가 기록되지 않도록
  방지.
- 저장 시 실제 적용된 서버/모델 값을 채팅에 안내 메시지로 표시.

## 검증

실제 창에서 "① 안 건드리고 저장 → 오버라이드 안 됨, ② 값 바꿔 저장 → 정상
저장, ③ 재오픈 시 저장한 값이 흰 글씨로 그대로 보임" 전 과정을 자동 재현해
확인. 기존 회귀 테스트 재확인.
