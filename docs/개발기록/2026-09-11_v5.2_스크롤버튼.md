# v5.2 카카오톡 스타일 우하단 맨 아래로 스크롤 플로팅 원형 버튼 (2026-09-11)

- **카카오톡 스타일 우하단 원형 플로팅 스크롤 버튼 (`ScrollBottomButton`) 구현**:
  - 사용자 요청: 카카오톡과 동일하게 과거 대화를 읽기 위해 위로 스크롤했을 때, 우하단에 나타나 원클릭으로 최신 메시지(맨 아래)로 이동할 수 있는 원형 버튼 추가.
  - 디자인: 직경 38px의 화이트 원형 캡슐 배경(`create_oval`)과 2.5px 정밀 벡터 셰브론(`∨`) 라인 렌더링.
  - 호버 인터랙션: 마우스 오버 시 연회색 하이라이트(`#f3f4f6`) 및 보더 강조, 손가락 커서(`hand2`) 피드백.
  - 배치: 대화 캔버스 우하단(`relx=1.0, rely=1.0, x=-16, y=-16, anchor="se"`), 스크롤바 좌측에 떠서 텍스트와 겹치지 않도록 깔끔하게 플로팅(`tk.Misc.lift`).
  - 마우스 휠 이벤트 포워딩: 버튼 위에 마우스 커서가 올라간 상태에서 마우스 휠을 굴려도 대화창 스크롤이 끊김 없이 부드럽게 연동.
- **자동 감지 표시/숨김 및 부드러운 감속 스크롤 (`_scroll_to_bottom`)**:
  - `yscrollcommand` 콜백 래퍼를 통해 마우스 휠, 스크롤바 드래그, 창 크기 조절 등 모든 스크롤 동작을 100% 감지.
  - 맨 아래에 있거나(`last >= 0.98`) 대화 내용이 한 화면에 다 들어오는 경우 자동 숨김(`place_forget`).
  - 과거 대화를 보러 위로 스크롤 시(`last < 0.98`) 즉각적이고 자연스럽게 플로팅 버튼 표시.
  - 버튼 클릭 시 100ms 7단계 감속 곡선(Ease-Out Quadratic)을 통해 부드럽고 쾌적하게 최신 대화 위치로 자동 스크롤 후 버튼 자동 숨김.
