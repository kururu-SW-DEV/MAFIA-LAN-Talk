# v1.43 — 마피아 테마 아이콘 교체 (2026-09-18)

## 사용자 지적
"일단 아이콘을 바꿀거야. 기존 말고 마피아 게임에 맞게 아이콘을 바꿔줘"

## 조치

- `app.ico`(기존 LAN Talk 범용 아이콘)를 마피아 테마로 교체. 외부 이미지
  소스 없이 PIL로 직접 그림 — 중절모(fedora) 실루엣 + 빨간 눈 포인트,
  다크 레드 그라데이션 원형 배경.
- 16px처럼 작은 크기에서도 형태가 뭉개지지 않도록 고대비(검정 모자 +
  흰색 밴드, 밝은 빨강 눈)로 조정 — 저대비 1차 시안은 32px에서 잘 안 보여
  다시 작업함.
- 16/20/24/32/40/48/64/128/256px 9개 크기를 전부 포함한 표준 멀티사이즈
  ICO로 저장.
- 기존 아이콘은 `app.ico.bak_original`로 백업(복원 가능).
- exe 빌드 시 쓰이는 `netutils.ICO_EMBED`(base64 내장)는 `build_exe.py`가
  빌드 파이프라인 중 `build_ico_embed.py`로 새 아이콘을 자동 반영하도록
  이미 되어 있어 별도 조치 불필요.

## 검증

- `PIL.Image.open('app.ico').info['sizes']`로 9개 크기 전부 포함 확인
- 128px/32px/16px 축소 렌더링을 실제로 확인해 저해상도에서도 형태 인식
  가능함을 확인
