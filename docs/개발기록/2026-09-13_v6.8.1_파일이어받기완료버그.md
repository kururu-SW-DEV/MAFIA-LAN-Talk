# v6.8.1 파일 이어받기 청크 배수 완료 결함 수정 및 안정성·UX 패치 (2026-09-13)

- **파일 전송 이어받기(Resume) 완료 처리 및 버퍼 안전성 결함 수정 (`engine.py`)**:
  - **버그 원인**: 수신 측에서 `actual_size % FILE_CHUNK_SIZE == 0 and actual_size <= size` 조건으로 `resume_from = total`을 반환할 경우, 발신 측이 `resume_from >= total`을 보고 전송할 조각이 없다고 판단해 `file_chunk`를 전송하지 않아 수신 측의 `_finish_incoming_file` 완료 파이프라인이 발화되지 못하고 `transfers_in`에 갇혀 있다가 증발하는 결함 해결.
  - **해결책**: 이미 전부 받아진 파일(`actual_size == size`)이더라도 마지막 1개 청크(`total - 1`)는 재수신하도록 `resume_from = max(0, total - 1)`로 교정하고, 수신 버퍼 파일(`.part`)을 `resume_from * FILE_CHUNK_SIZE`로 정확히 `truncate`하여 이어쓰기 시 오버플로/크기 불일치 오류를 원천 차단.
  - **고아 파일 누적 방지**: `_finish_incoming_file`에서 파일 이동(`shutil.move`) 실패 시 잔여 `.part`를 자동 삭제하고, `_prune()` 워커에서 `self.partial_dir`의 7일 이상 경과한 고아 `.part` 파일 디스크 자동 스캔/정리 추가.
- **`get_category()` 멀티스레드 안전성 강화 (`engine.py`)**:
  - `with self.settings_lock:`을 적용하여 다중 스레드 환경에서 안전한 카테고리 조회 보장.
- **다중 발송(`_broadcast_dialog`) 단축키 추가 (`app.py`)**:
  - `<Control-Return>` 및 `<Control-KP_Enter>` 바인딩으로 마우스 클릭 없이 키보드만으로 즉시 전송 가능하도록 개선.
- **채팅 캔버스 마우스 휠 바인딩 충돌 방어 (`app.py`)**:
  - 마우스가 채팅창으로 진입 시 `self.plist.unbind_all("<MouseWheel>")`을 호출하여 사이드바의 마우스 휠 전역 가로채기가 잔류하는 현상 방어.
- **Windows 바로가기 생성 무음 처리 (`winapi.py`)**:
  - `os.system` 대신 `subprocess.run(..., creationflags=0x08000000)`(`CREATE_NO_WINDOW`)을 사용하여 시작 시 콘솔 창 깜빡임 완전 제거.
- **Windows 알림 팝업 이중 아이콘 제거 및 레이아웃 최적화 (`winapi.py`)**:
  - **문제 현상**: Windows 10/11 알림 팝업(토스트) 발생 시, 상단 헤더의 작은 앱 아이콘 외에도 본문 하단/좌측에 거대한 정사각형 아이콘이 중복으로 노출되어 시각적 공간을 과도하게 차지하고 레이아웃이 어색한 결함 ("상단 작은 아이콘은 유지, 하단 큰 아이콘 제거" 요청).
  - **원인 분석**: `winapi.py`의 `notify()`에서 `nid.dwInfoFlags = NIIF_USER | NIIF_LARGE_ICON` 및 `nid.hBalloonIcon = self._h_icon`을 명시함에 따라, Windows Shell(Explorer)이 트레이 풍선을 Windows 10/11 토스트로 변환할 때 `<image id="1">` 태그를 삽입하는 `ToastImageAndText02` 템플릿으로 렌더링하여 본문에 대형 이미지를 중복 배치함.
  - **해결책**: `nid.dwInfoFlags = NIIF_NONE` (0x0) 및 `nid.hBalloonIcon = None`으로 교정. Windows 알림 플랫폼이 이미지를 생략하고 `ToastGeneric` 텍스트 단독 레이아웃으로 렌더링하게 하여, 상단 헤더의 단일 공식 LAN Talk 아이콘만 남기고 본문의 거대한 중복 아이콘을 완벽하게 제거.
  - **테스트 알람 발송 및 검증**:
    - `Shell_NotifyIconW(NIM_MODIFY)` 및 WinRT Toast API(`ToastNotificationManager`)를 활용한 실시간 알림 전송 파이프라인 검증.
    - Windows 알림 내부 데이터베이스(`wpndatabase.db`)의 페이로드 XML 및 실제 사용자 데스크톱 세션 알림 발송 검증 완료.
- **비활성 스크롤바 상황 마우스 휠 조작 시 캔버스 내용 표류(Drift) 결함 수정 (`canvas_utils.py`, `app.py`, `widgets.py`)**:
  - **문제 현상**: 대화 목록이나 채팅창 내용이 화면 안에 모두 들어가 스크롤할 필요가 없어 스크롤바가 비활성화된 상태에서 마우스 휠을 굴리면, 캔버스 안의 목록이나 대화 말풍선이 화면 아래로 50px씩 계속 밀려 내려가 빈 공간이 생기거나 어긋나는 결함.
  - **원인 분석**: Tkinter Canvas 내부 구현(`tkCanvUtil.c`)상 `scrollregion` 높이가 캔버스 뷰포트 높이보다 작거나 같을 때, `yview_scroll`에 휠 회전 유닛이 전달되면 경계 검사가 실패하여 캔버스 내부 `yOrigin` 좌표가 음수(`-50px`, `-150px` 등)로 표류(Drift)하게 됨.
  - **해결책**:
    - `safe_canvas_mousewheel(canvas, event_or_delta)` 안전 스크롤 헬퍼 함수를 `canvas_utils.py`에 신설.
    - `(bot - top) >= 0.999` 조건을 판정하여 스크롤바가 필요 없는 상태에서는 `yview_scroll` 호출을 원천 차단하고 `yview_moveto(0.0)`으로 좌표를 완벽히 고정.
    - 스크롤이 필요한 경우에도 상단(`top <= 0.001` 휠 업) 및 하단(`bot >= 0.999` 휠 다운)에서 경계를 벗어나지 않도록 안전 클램핑 보장.
    - 좌측 대화 목록(`self.plist`), 우측 채팅 캔버스(`self.chat`), 맨 아래로 플로팅 버튼(`ScrollBottomButton`), 다이얼로그 캔버스 전역에 일괄 적용.
- **검증**: `test_mousewheel_fix.py` (내용 부족 상태 30회 휠 조작 무변형 검증, 대용량 내용 스크롤/상단 클램핑 검증, App GUI 통합 검증) 및 `test_resume_fix.py`, 전체 회귀 테스트 통과.
