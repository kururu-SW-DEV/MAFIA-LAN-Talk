# v1.04 — 최후 변론 찬/반 반응 지연·개표 멈춤 해소 (2026-09-17)

## 사용자 지적
"처형찬성/만류 메뉴를 누르면 바로 반응을 안하고 한참 있다가 프로그램이
반영하네... 그러면서 개표중만 뜨다가 멈춰버려"

## 원인 (실측 확정)

1. **AI 찬반 투표가 LLM `say`를 기다렸음** — AI마다 2~5초 + `after(1200)`
   → 유저가 표를 던져도 한참 뒤에만 AI 표가 채워짐 ("바로 반응 안 함")
2. **AI `say` 실패 시 표가 아예 안 찍힘** → `defense_all_voted()`가 영원히
   False → 개표가 처음부터 안 진행 ("개표중에서 멈춰버려" 그 자체)

## 수정

| 항목 | 내용 |
|---|---|
| AI 찬반 결정 | LLM 대신 **인격/역할 기반 즉시 결정**(400~350ms 간격 스캔) — 경찰이 이미 조사한 사용자가 대상이면 그 판정 반영 |
| 즉시 개표 체크 | `_maybe_resolve_defense()` — 유저·AI 표가 다 모이는 즉시 300ms 후 개표 |
| 안전망 30초 | `_defense_deadline` — 30초 후 미투자를 기권(반대) 취급하고 **강제 개표** |
| 타이머 정리 | `_clear_defense_deadline()` — 개표 후 오래된 after가 재개표하는 것 방지 |

## 실측 (통과)

```
roles: 정민호=mafia, 김과장=citizen, 지은=doctor, 현우=citizen
user vote (찬성)
resolved in 1.3s      ← 유저 표 → AI 표 3건(350ms 간격) → 개표 즉시
final phase: day      (변론 결과 반영 OK)
```
