# v1.19 — 유저 사망 후 AI끼리 게임 '개표 중 정지' 해소 (2026-09-18)

## 사용자 지적
"내가 죽고 AI끼리 게임을 진행하는데, 지들끼리 투표하는거는 개표 중에서 끝나버리네"

## 원인 (실측 확정)

유저 사망 시에도 **재투표 팝업과 최후변론 찬반 팝업이 유저 화면에 열렸음**:
1. 유령방 자동 오픈(사망 안내) 이후 재투표/찬반 overlay가 뒤로 가려져
   유저 눈에는 '🗳 개표 중…' 라벨만 남고 정지한 것처럼 보임.
2. 유저가 사망자라 클릭할 수 없으니 **30초 무응답 안전망만 타는 구조** —
   AI끼리 게임인데 유저 인터랙션 30초 대기가 섞여 진행이 답답하게 느껴짐.

## 조치 (v1.19)

| 항목 | 내용 |
|---|---|
| 유저 사망 재투표 | 팝업 개봉 생략 + "👻 사망자 재투표 참관 모드" 안내 → AI 표 300ms 간격 즉시 접수, 25초 안전망만 유지 |
| 유저 사망 찬반 | 팝업 개봉 생략 + "👻 사망자 찬반 투표권 없음" 안내 → AI 표만으로 진행, 30초 안전망 유지 |
| 관찰 흐름 | 사망 유저는 유령방(참관) + 게임방 시스템 라인(개표/투표 접수)로 진행 실황 관측 |

