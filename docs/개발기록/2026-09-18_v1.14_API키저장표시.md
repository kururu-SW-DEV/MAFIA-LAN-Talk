# v1.14 — API 키 설정창 '말로는 저장 성공, 보여주기 누락' + 저장 경로 폴백 (2026-09-18)

## 사용자 지적
"API키 설정 창에 입력한거 저장이 안되는데 확인해봐"

## 원인 (실측 확정)

1. **API Key 입력창이 항상 빈칸으로 열림** — [저장]에서 실제로는
   `mafia_llm.json`에 기록되고 있었으나, **다시 설정창을 열 때 저장된 키가
   입력창에 표시되지 않아** 유저가 "저장이 안 됐다"고 판단.
2. **datadir이 None일 때 저장 경로가 없음** — `set_overrides_file(None)`이면
   `_OVERRIDES_FILE = None` → `save_overrides()`가 조용히 False가 되었음.
   (Desktop 배포에서 args.datadir이 항상 지정되는 게 아니라는 케이스 대비)

## 조치 (v1.14)

| 항목 | 내용 |
|---|---|
| 기존 키 표시 | 설정창 열 때 `saved_key`가 있으면 마스킹("abcd…xyz") + '✔ 기존 키가 저장됨' 초록 라벨 |
| 포커스 시 자동 클리어 | 입력창에 클릭/탭 하면 미리보기 마스크가 자동 사라짐 — 새 키를 바로 입력 가능 |
| placeholder 저장 방지 | 마스크가 placeholder일 때는 그 값을 그대로 저장하지 않음('…' 포함 감지) |
| 저장 경로 폴백 | `_ensure_overrides_file()` — datadir이 없으면 `%LOCALAPPDATA%\MAFIA\mafia_llm.json` 자동 사용 |
| save/load 재시도 | `save_overrides`·`load_overrides` 둘 다 폴백 경로 확보 후 동작 |
