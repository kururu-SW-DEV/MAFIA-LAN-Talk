# 상용 메신저급 4대 고도화 개발 기록 (v6.3, 2026-09-12)

사용자 분석을 바탕으로 상용 메신저(카카오톡, 슬랙, 텔레그램) 대비 핵심 기능 격차 4가지를 100% 순수 표준 라이브러리로 완성했습니다:

### 1. 그룹 오프라인 캐치업 (Group Offline Catch-up)
- **배경**: 1:1 대화와 달리 그룹 대화(`send_group_message`)는 수신자가 일시 오프라인일 때 패킷이 버려져 해당 멤버만 메시지를 영구히 받지 못하는 결함 존재.
- **구현**:
  - 그룹 멤버별 유니캐스트 전송 콜백에서 전송 실패(`not ok`) 시 `self._enqueue_outbox(target_ip, target_port, packet)`를 호출하여 로컬 `outbox.json`에 영속화.
  - 상대방이 온라인으로 복귀하여 `presence` 브로드캐스트가 수신되면, `_flush_outbox(ip, port)`가 큐에 있던 그룹 대화를 자동으로 순차 재전송.
  - 전송 성공 시 `gsent` 이벤트를 발행하고 outbox에서 즉시 제거.

### 2. 단체방 읽음 확인 카운트다운 (Group Read Receipts Countdown)
- **배경**: 1:1 대화에만 존재하던 읽음 확인('1')을 단체방으로 확장하여, 내가 보낸 메시지를 몇 명이 읽었는지 실시간 파악할 필요성 대두.
- **구현**:
  - `gread_ack` 패킷 프로토콜 정의: `{"type": "gread_ack", "gid": gid, "mid": mid, "port": port, "tid": instance_id}`.
  - 그룹 대화 발신 시 메시지 수신 대상 인원수로 `unread_count` 초기화 (예: 3인방 기준 2).
  - 그룹원들이 대화방을 열거나 활성 상태에서 수신 시 `send_group_read_ack(gid, mid)` 발송.
  - 발신자는 `_mark_group_read_in_log`를 통해 읽은 멤버를 기록하고 `unread_count`를 실시간 차감(`2 -> 1 -> 0`).
  - UI 렌더러(`_draw_label`)에서 카카오톡 스타일의 주황색 숫자 배지로 시각과 함께 렌더링되며, 전원이 읽으면(0) 배지가 깔끔하게 사라짐.

### 3. `@이름` 멘션 및 자동완성 (Mention Autocomplete & Highlighting)
- **배경**: 여러 명이 대화하는 단체방에서 특정 상대를 지목하여 주의를 환기하고 호출할 수 있는 기능 필요.
- **구현**:
  - `widgets.py:MentionPopup(tk.Toplevel)`: 입력창 위젯 상단에 플로팅되는 다크 테마 커스텀 자동완성 팝업.
  - 사용자가 입력창에서 `@` 타이핑 시 현재 방의 멤버 목록을 기반으로 후보군을 실시간 필터링.
  - 키보드 방향키(`▲`/`▼`)로 후보 탐색, `Tab` 또는 `Enter`로 자동완성 삽입(`@이름 `), `ESC`로 팝업 닫기 지원.
  - 수신된 메시지에 `@내이름`이 포함되어 있으면 말풍선 테두리를 화사한 하늘색(`#38bdf8`)으로 하이라이트.
  - Windows 알림 센터 토스트에 `[멘션] 홍길동 · 방이름`으로 강조 알림.

### 4. 전체 대화 통합 풀텍스트 검색 (Global Message Search)
- **배경**: 특정 방 안에서만 작동하던 대화방 검색(`Ctrl+F`)을 넘어, 모든 1:1 방과 단체방의 방대한 대화 기록을 한 번에 검색할 수 있는 기능 필요.
- **구현**:
  - `engine.py:search_all_logs(query, limit=50)`: `logs/` 디렉토리 내의 모든 1:1(`*.jsonl`) 및 단체방(`group_*.jsonl`) 로그를 고속 스트리밍 스캔하여 키워드 매칭 레코드 추출.
  - 사이드바 상단 검색창에 검색어 입력 시, 대화 목록 하단에 **"메시지 검색 결과 (N건)"** 섹션이 동적으로 표시됨.
  - 검색 결과 클릭 시: 1) 해당 방으로 즉시 대화 전환(`_select(key)`), 2) 해당 메시지 인덱스로 자동 스크롤(`_scroll_to_match`), 3) 상태바 안내 표시.

### 5. P2P 네트워크 레이어 버그 근본 해결 & 내결함성·보안 강화
- **그룹 나가기(leave_group) 가십 부활 방지 및 오프라인 아웃박스 연동**:
  - 원인: `leave_group()` 시 `group_leave` 알림이 단순 UDP 발송되어 오프라인 멤버가 놓치고, 이후 해당 멤버가 보낸 가십 패킷(합집합 union)에 의해 이미 나간 사람이 그룹에 조용히 재등록되는 심각한 결함 존재.
  - 해결: 1) `group_leave` 패킷을 `_send_reliable()`로 발송하고 미응답 시 `outbox.json`에 큐잉하여 상대 복귀 시 자동 재전송, 2) 각 그룹에 `left` 묘비(Tombstone) 집합을 두어 어떤 가십 패킷이 와도 탈퇴자는 union에서 원천 제외, 3) `self.left_groups`를 영속화하여 나간 그룹이 다시 생성되는 현상 차단.
- **파일 수신 측(Receiver) 크기 상한 및 청크 한도 검증**:
  - 원인: 발신 측만 20MB를 검사할 뿐, 수신 측 `file_offer` / `file_chunk`는 크기를 맹신하여 대용량 공격이나 청크 누적 DoS에 취약.
  - 해결: `file_offer`에서 `size > MAX_FILE_SIZE (20MB)` 및 `total > max_chunks` 즉시 드롭, `file_chunk`에서 비정상 크기 청크 필터링 및 조립 후 최종 길이 검속.
- **`safe_name` 경로 탈출 문자열(`.`, `..`) 방어**:
  - 원인: 구분자 치환만 수행하여 `.` 또는 `..` 단독 파일명이 들어오면 `os.path.join(download_dir, "..")`로 상위 폴더 경로가 계산되는 취약점.
  - 해결: 후행 공백/점 필터링 및 `.` 또는 `..` 단독/반복 문자열일 경우 `"peer"`로 대체하여 경로 탐색 원천 방어.
- **그룹 패킷 ACK 충돌 방지**:
  - 원인: `send_group_message` 시 모든 멤버에게 동일한 메시지 ID(`pkt["id"] = mid`)를 부여하여, 1명의 ACK 수신이 다른 멤버 전송 대기 Event까지 unblock 시키는 레이스 컨디션 발생.
  - 해결: 전송 패킷별 고유 `pkt_id = uuid.uuid4().hex`를 부여하여 UDP 신뢰 전송 워커 간 Event 경합을 완전 분리하고, 메시지 본문에는 논리적 `pkt["mid"] = mid`를 유지.
- **최근 수신 메시지 중복 필터링 (`_seen_mids`)**:
  - UDP 네트워크 재전송이나 동시 플러시로 인한 중복 패킷 도착 시, 발신자에게 ACK는 즉시 응답하되 수신 측에서는 로그 기록 및 UI 이벤트 중복 발행을 완벽 차단.
- **아웃박스 동시 실행 방지 락 (`_flushing_targets`)**:
  - 동일한 상대에게 presence 신호가 연속 수신되더라도 병렬 플러시 스레드가 중복 생성되지 않도록 보호.
