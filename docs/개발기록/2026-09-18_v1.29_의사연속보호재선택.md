# v1.29 — 의사 연속 보호 거절 UX + 채팅 경로 우회 결함 수정 (2026-09-18)

## 사용자 지적
"의사가 저번턴이랑 같은 대상을 치료하려고 하면 오류 메시지가 나오고 재 치료가 안돼"

## 원인 (E2E 실측 확정) — 2건

1. **거절 직후 패널 즉시 닫힘** — 밤 행동 패널에서 이미 보호한 대상을 누르면
   `doctor_protect`가 거절(False)하고 경고 문구가 뜨지만, 바로
   `_mafia_overlay_close()`로 패널이 닫혀 버림 → **'다른 대상을 다시 누르는'
   기회 자체가 없어** '재 치료가 안 된다'로 체감 (진원지).
2. **채팅 '구조 이름' 경로 검증 우회** — 채팅 명령은 `set_night_save`를
   직접 호출, 연속 보호 금지 검증(`doctor_protect`)을 거치지 않음 + 자투
   금지(본인 구조) 차단도 빠져 있음 — 패널과 기준 불일치.

## 조치 (v1.29)

| 항목 | 내용 |
|---|---|
| 패널 유지 | 거절 시 안내 문구 표시 후 **패널을 닫지 않고 유지**(return) — 즉시 다른 대상 재클릭 가능 |
| 보호 성공 시 | 기존대로 접수 후 패널 닫기 |
| 채팅 경로 정합 | '구조 이름'도 `doctor_protect`로 검증 — 거절 시 안내+재입력 방법 제시 |
| 자투 차단 추가 | 채팅 경로에서 본인 구조 명령 차단 (패널과 동일 기준) |

주의: '연속 보호 금지' 규정 자체는 유지 — 저번 밤과 같은 대상을 또
보호하는 것은 앞으로도 불가. 이번 수정은 거절 후 **다른 대상으로 바로
재선택하는 경험**을 살리는 것.

## 실측 (E2E)

```
동일 대상 클릭 → 거절 안내 표시 + 패널 유지 확인
다른 대상 클릭 → '김과장' 구조 접수 성공 (night_saved='김과장')
채팅 '구조 현우' → '연속 보호 금지' 안내 출력 확인
```
