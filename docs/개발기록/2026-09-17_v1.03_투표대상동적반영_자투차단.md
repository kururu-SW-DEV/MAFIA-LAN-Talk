# v1.03 — 투표 대상 동적 반영·자투 차단 (2026-09-17)

## 사용자 지적
"투표 대상이 하드 코딩되어 있어서 실제 참가자의 명단과 달라"

## 조사 결과 (실측)

전수 검토 결과 **투표 대상 자체는 전부 core.alive_players() 기반**이었고,
하드코딩된 참가자 이름은 없었습니다. 실측:
```
참가자: 정민호(사람), 김과장, 지은, 현우 (AI)
popup buttons: ['정민호', '김과장', '지은', '현우']
button matches alive players: True
```

## 그러나 발견된 진짜 결함 2건 — 이게 "하드코딩처럼 보였던" 원인

1. **자투(나 자신 투표) 허용** — cast_vote("정민호", "정민호")가 True.
   투표 팝업 버튼에 **나 자신도 후보로 노출** — 자기 이름이 대상에
   섞여 있는 것을 "실제 참가자 명단과 다르다"고 받아들일 수 있음.
2. **밤 살해 자기/동료 마피아 지목 허용** — 마피아가 자기 자신을 지목 가능.

## 수정
- `cast_vote`: `target == voter`면 `False` (자투 금지)
- `set_night_target`: 마피아(본인·동료) 지목 시 `False`
- `_show_vote_popup`: 버튼 후보에서 `me` 제외 → **나 자신은 후보로 안 나옴**

## 실측 (통과)
```
self-vote blocked: False     (자투 금지)
normal vote: True            (다른 참가자 투표 OK)
mafia self-vote blocked: False  (마피아 자기 지목 금지)
mafia kill other: True
popup buttons: ['김과장', '지은', '현우']   ← 나(정민호)는 후보 제외
me excluded: True
```
