# v6.40 — 파일 전송·다운로드 최대 크기를 설정에서 조절 가능하게 (2026-09-14)

## 계기

기존에는 파일/사진 전송·수신 최대 크기가 `constants.py`의 `MAX_FILE_SIZE`
(20MB) 하드코딩값이었다. 사용자가 이 제한을 1~1024MB(1GB) 사이에서 직접
타이핑으로 설정할 수 있게 해달라고 요청했다.

## 구현

- **`constants.py`**: `MAX_FILE_SIZE` → `DEFAULT_MAX_FILE_SIZE`(기본값,
  20MB)로 이름을 바꾸고, 사용자가 설정할 수 있는 상한
  `MAX_FILE_SIZE_LIMIT_MB = 1024`(1GB)를 추가.
- **`engine.py`** (`Engine`):
  - `__init__`에서 `self.max_file_size`를 `settings.json`의
    `max_file_size_mb`(없으면 기본 20MB)로부터 로드. 이름(`name`) 설정을
    저장/로드하던 것과 동일한 패턴.
  - `_clamp_file_size_mb()`: 값을 1~1024 사이로 강제하고, 손상됐거나
    없으면 기본값(20)으로 되돌리는 정적 메서드.
  - `set_max_file_size_mb(mb)`: 클램프 후 `self.max_file_size`를 갱신하고
    `settings.json`에 저장, 실제 적용된 MB 값을 반환.
  - 파일 크기 검사 4곳(`send_file`, 수신측 `file_offer`의 청크 개수 상한,
    수신 완료 후 크기 검증)을 전부 상수 `MAX_FILE_SIZE` 대신
    `self.max_file_size`를 보도록 교체. 상대방이 보낸 `file_offer`도 **내
    쪽 설정값** 기준으로 거부하므로, 두 사람의 설정이 다르면 각자 자기
    한도로 판단한다(받는 쪽 기준 "다운로드 제한"이라는 요청 취지에 부합).
  - `app.py`의 파일 선택 시 크기 검사도 `self.engine.max_file_size`로 교체.
- **`dialogs.py`** (`_settings_dialog`, 창 제목을 "상대 연결"에서 "설정"으로
  변경): 기존 "상대 연결"(IP 직접 추가) 섹션 아래에 "파일 전송·다운로드
  최대 크기" 섹션을 새로 추가.
  - MB 단위 숫자만 입력하는 Entry + [적용] 버튼(Enter로도 적용).
  - 범위(1~1024) 밖이거나 숫자가 아니면 빨간 안내문, 정상 적용되면
    초록색으로 "OOMB로 적용되었습니다" 표시.
  - 창 높이를 400→520으로 늘림.
- **`lan_messenger.py`**: 하위 호환 재노출용 임포트도
  `DEFAULT_MAX_FILE_SIZE`로 함께 교체.
- **`tests/test_headless.py`**: "20MB 초과 파일 즉시 거부" 테스트가
  더는 존재하지 않는 `lm.MAX_FILE_SIZE` 대신 실제 엔진 인스턴스의
  `A.max_file_size`를 기준으로 큰 파일을 만들도록 수정.

## 검증

- `python -m py_compile`로 관련 파일 전부 컴파일 확인.
- `tests/test_headless.py` 전체 재실행 — 파일 전송 관련 4개 케이스(청크
  분할·조립, 파일명 충돌 넘버링, 크기 초과 즉시 거부, 그룹 파일 팬아웃)
  포함 전부 `ALL PASSED`.
- 별도 스크립트로 `Engine.set_max_file_size_mb()`의 경계값(0→1로 클램프,
  99999→1024로 클램프, 500 정상 적용)과, 앱을 재시작한 것처럼 새
  `Engine` 인스턴스를 만들어 `settings.json`에서 500MB 설정이 그대로
  로드되는 것까지 직접 확인.
