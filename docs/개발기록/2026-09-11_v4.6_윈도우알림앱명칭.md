# v4.6 Windows 알림창(토스트) 아이콘·이름(Lan Messenger) 변경 및 앱 명칭 일괄 개편 (2026-09-11)

- **Windows 알림창 헤더 '파이썬' → 'Lan Messenger' 및 커스텀 아이콘(`app.ico`) 표시**:
  - 기존 Windows 알림 토스트 시 상단 헤더에 "Python" 및 파이썬 기본 아이콘이 노출되던 문제를 근본 해결.
  - Windows AUMID (`APP_AUMID = "LanMessenger"`)를 정의하고 `SetCurrentProcessExplicitAppUserModelID`를 호출하여 현재 프로세스를 전용 앱으로 명시 등록.
  - 레지스트리 `HKCU\Software\Classes\AppUserModelId\LanMessenger`에 `DisplayName` ("Lan Messenger"), `IconUri` (`app.ico`), `ShowInSettings` (1)를 자동 등록.
  - Windows 시작 메뉴 프로그램 폴더(`%APPDATA%\Microsoft\Windows\Start Menu\Programs`)에 `Lan Messenger.lnk` 바로가기를 자동 생성하여 Windows 10/11 알림 센터가 앱 이름과 아이콘을 완벽하게 인식하도록 구축.
  - `NOTIFYICONDATA`에 `NIIF_USER (0x4)`와 `NIIF_LARGE_ICON (0x20)` 및 `hBalloonIcon`을 적용하여 풍선 알림 본문에도 파이썬 기본 `(i)` 대신 고해상도 Lan Messenger 전용 아이콘이 렌더되도록 개선.
- **앱 전반 명칭을 '사내 메신저'에서 'Lan Messenger'로 일괄 개편**:
  - 윈도우 타이틀바: `root.title("Lan Messenger")`
  - 프로필 서브텍스트: `Lan Messenger · 서버 없음`
  - 상태바 및 시작 실패 다이얼로그 문구: `Lan Messenger P2P 전용 · 서버 없음`
  - 명령행 파서(`argparse`): `Lan Messenger — 서버 없는 P2P (UDP 알고리즘)`
- 검증: `smoke_gui.py`, `test_headless.py`, `test_gui_flow.py`, `test_new_features.py` 전 테스트 통과 및 AUMID 레지스트리·시작 메뉴 바로가기 생성 검증.
