# v6.28 — 종합 최적화·스티커 스크롤바 수정·사이드바 깜빡임 제거·고해상도 아이콘 (2026-09-13)

## 계기 및 배경

메신저 고도화 작업 및 사용자 피드백을 통해 접수된 성능 병목 현상, UI 렌더링 결함, 조작성 문제, 스레드 동시성 이슈를 종합적으로 분석하고 전면 해결했습니다.

1. **상단 타이틀바 색상 및 창 복원 번쩍임**: 타이틀바가 흰색으로 뜨거나 창 최소화→복원 시 번쩍거리는 현상.
2. **숨긴 대화 복원 카운트 오류**: 숨긴 대화를 복원해도 개수가 줄어들지 않아 무한 생성처럼 보이던 문제.
3. **상대방 호출 시 대화 목록 미노출**: 상대방이 먼저 대화를 시작했을 때 사이드바 목록에 즉시 반영되지 않던 문제.
4. **작업표시줄 아이콘 저해상도 및 파이썬 마크 노출**: 작업표시줄에 파이썬 기본 로고가 보이거나 저해상도(16px) 아이콘이 늘어나 흐릿해 보이던 현상.
5. **스티커 방 최초 로딩 1.5초 지연**: 스티커를 사용한 대화방을 열 때마다 부드러운 원형 배경 연산으로 인해 1.5초 멈칫거림 발생.
6. **사이드바 3초 주기 깜빡임/떨림**: 3초 주기 피어 폴링 시마다 전체 행이 `pack_forget` / `pack` 재배치 및 아바타 재작도로 깜빡이던 현상.
7. **스티커 피커 스크롤바 소실 및 휠 스크롤 불가**: 창 크기가 작을 때 스티커 메뉴 내 스크롤바가 1x1px로 찌그러져 사라지고, 마우스 휠 스크롤이 작동하지 않던 문제.
8. **채팅창 내 스티커 간격 과밀**: 스티커 메시지 간의 상하 간격이 좁아 답답해 보이던 레이아웃.
9. **네트워크 엔진 스레드 락 및 I/O 블로킹**: `_prune()` 검사 중 락을 쥔 채로 디스크 I/O를 수행하여 통신 스레드가 일시 프리징될 수 있던 위험.
10. **대화방 검색 (Ctrl+F) 하이라이트 가림**: 검색된 말풍선 강조 사각형이 불투명 말풍선 배경 뒤로 숨어 눈에 띄지 않던 결함.

## 주요 원인 분석 및 수정 내역

### 1. 상단 타이틀바 색상 및 DWM 번쩍임 방지 (`winapi.py`)
- **원인**: Windows DWM 속성을 창 생성 직후 적용할 때 HWND 타이밍에 따라 적용이 무시되거나, `<Map>` 이벤트마다 `SWP_FRAMECHANGED`를 재호출하여 최소화/복원 시 번쩍임 유발.
- **수정**: `<Map>` 이벤트에 1회성 가드(`_mapped_once`)를 두어 최초 창 노출 시에만 DWM 다크 캡션 및 테마 색상을 안정적으로 적용하고, 이후 최소화→복원 시에는 재도장 플래그를 생략하여 번쩍임을 완전히 방지.

### 2. 숨긴 대화 복원 카운트 및 목록 상태 동기화 (`app.py`)
- **원인**: `_unhide_all()` 실행 시 메모리 상의 `self.engine.hidden` 세트가 즉시 비워지지 않고 비동기 파일 저장 타이밍과 어긋나 복원 카운트가 줄어들지 않던 문제.
- **수정**: 복원 즉시 `self.engine.hidden.clear()` 후 `_save_hidden_conversations()`를 강제 동기화하고, 사이드바 목록과 뱃지 카운트를 즉시 0으로 재계산하도록 보정.

### 3. 상대방 호출 시 실시간 목록 즉시 등록 (`app.py`, `engine.py`)
- **원인**: 상대방이 먼저 메시지를 보냈을 때 `_on_msg_recv()`에서 해당 피어가 `known_peers`에 없으면 3초 폴링 주기 전까지 사이드바에 늦게 나타남.
- **수정**: 수신 핸들러에서 새 피어 감지 시 즉시 `_save_known_peers()`를 호출하고 메인 스레드에 사이드바 갱신 이벤트를 디스패치하여 즉시 목록 상단에 대화방이 노출되도록 개선.

### 4. 고해상도 멀티사이즈 작업표시줄 아이콘 생성 및 적용 (`assets/icon.ico`, `app.py`)
- **원인**: Windows 작업표시줄이 `python.exe` 프로세스로 그룹화되면서 파이썬 기본 아이콘이 노출되거나, 단일 저해상도(16px) 아이콘이 48px/64px로 늘어나 계단 현상 발생.
- **수정**:
  - 16, 24, 32, 48, 64, 128, 256px 등 7단계 해상도를 모두 포함하는 고품질 `assets/icon.ico`를 새로 생성.
  - Windows ctypes `SetCurrentProcessExplicitAppUserModelID("LANTalk.Messenger.App")`를 호출하여 OS 작업표시줄이 파이썬과 분리된 독립 앱으로 인식하도록 처리.
  - `WM_SETICON` 메시지를 통해 `ICON_BIG` 및 `ICON_SMALL`에 고해상도 네이티브 HICON 핸들을 등록하여 작업표시줄과 타이틀바 모두 선명한 로고 유지.

### 5. 스티커 채팅방 진입 0초 즉시 로딩 (`stickers.py`, `app.py`)
- **원인**: 스티커 메시지를 렌더링할 때 배경의 부드러운 원형(`smooth_circle_photo`) 28종을 매번 처음부터 PIL/파이썬 루프(14만 회 이상)로 연산하여 1.5초가량 멈칫거림 발생.
- **수정**:
  - `stickers.prewarm_stickers()` 함수를 작성하여 앱 기동 직후 백그라운드 유휴 시간(`root.after_idle`)에 28개 스티커 배경 원(96px 대화방용 및 38px 선택창용)을 미리 생성해 메모리 캐시(`canvas_utils._smooth_circle_cache`)에 적재.
  - 기존의 불필요한 Segoe UI Emoji 폰트 예열 코드를 스티커 배경 예열로 전면 교체하여 **대화방 입장 지연을 0.01초 이하로 단축**.

### 6. 사이드바 깜빡임 완전 제거 (UI Diffing & State Caching) (`app.py`)
- **원인**: 3초 주기 피어 폴링 시마다 전체 대화방 행 위젯을 `pack_forget()` 후 다시 `pack()`하고, 캔버스 아바타를 지우고 새로 그려 화면 떨림 유발.
- **수정**:
  - **행 패킹 디핑(Diffing)**: 마지막으로 패킹된 대화방 키 목록(`_last_packed_keys`, `_last_packed_cats`, `_last_packed_tab`)을 기억하여, 순서나 탭에 변동이 없으면 `pack_forget` 및 `pack` 호출을 완전히 생략.
  - **시각적 상태 캐싱**: `_update_row()`에서 배경색(`_last_bg`), 아바타 상태(`_av_state`), 최근 메시지(`_last_prev`), 안 읽은 뱃지 표시 상태를 비교하여 변경이 없는 대화방은 캔버스 재작도를 건너뜀.

### 7. 스티커 피커 스크롤바 축소 소실 방지 및 휠 스크롤 지원 (`widgets.py`)
- **원인**:
  - `body_wrap` 내에서 `self.canvas.pack(side="left", fill="both", expand=True)`가 스크롤바 `sb.pack(side="right", fill="y")`보다 먼저 호출되어 창 너비가 좁을 때 캔버스가 가로 공간을 선점하며 스크롤바가 1x1px로 축소·소실.
  - 개별 스티커 위젯 위로 마우스가 올라가 있을 때 마우스 휠 이벤트가 부모 캔버스로 전파되지 않음.
- **수정**:
  - `sb.pack(side="right", fill="y", padx=(2, 2))`를 캔버스보다 먼저 패킹하여 항상 8px 너비를 온전히 보장.
  - `EmojiPicker`, `body_wrap`, `self.canvas`, `self.inner`, 개별 스티커 캔버스 셀 전체에 `<MouseWheel>` 핸들러를 바인딩하여 메뉴 어디에서든 매끄럽게 스크롤되도록 구현.

### 8. 채팅창 내 스티커 메시지 여백 최적화 (`app.py`)
- **수정**: 스티커 메시지가 연속으로 오거나 일반 텍스트와 섞여 있을 때 답답해 보이지 않도록 상하 패딩과 여백 간격을 조정하여 시각적 통기성 확보.

### 9. 엔진 멀티스레드 락 안전성 강화 및 I/O 블로킹 분리 (`engine.py`)
- **원인**: `_prune()` 주기 검사 중 `self.plock`을 획득한 상태로 디스크 I/O인 `os.path.exists(fpath)`를 호출하여 다른 통신 스레드가 락 대기 상태에 빠질 위험 존재.
- **수정**: 만료 후보 피어를 락 안에서 빠르게 추출한 후 디스크 검사는 락 바깥에서 수행하고, 실제 삭제 대상만 락을 다시 획득하여 정리하도록 분리. `get_group()`, `get_peer()` 스레드 안전 헬퍼 추가.

### 10. 대화방 검색(Ctrl+F) 하이라이트 시인성 개선 (`chat_search.py`)
- **원인**: 검색 일치 말풍선을 강조할 때 `self.chat.tag_lower(rect)`로 사각형을 맨 뒤로 보내 불투명한 말풍선 배경 뒤로 가려짐.
- **수정**: 말풍선 텍스트와 스티커를 전혀 가리지 않는 투명 채우기(`fill=""`)와 선명한 오렌지 테두리(`outline="#f59e0b", width=2`) 및 좌측 4px 액센트 바를 적용해 검색된 메시지가 즉각 눈에 띄도록 개선.
