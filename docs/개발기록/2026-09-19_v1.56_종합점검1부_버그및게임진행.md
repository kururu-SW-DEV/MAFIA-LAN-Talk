# v1.56 — 종합 점검 1부: 버그 수정 + 게임 진행 개선 (2026-09-19)

## 사용자 지적
"지금까지 작성된 코드의 버그, 게임 진행상황의 개선점, UI 디자인(버튼의
가운데 정렬 등), 디자인의 통일성 등을 종합적으로 검토해봐" → 감사 결과에
대해 "전부다" 수정 지시.

## 배경
서브에이전트로 `mafia_ui.py`/`mafia_core.py`/`mafia_ai.py`/`mafia_config.py`
전체를 감사해 file:line 단위로 문제를 정리한 뒤, 카테고리별로 순차 수정.
이 문서는 그중 **버그**와 **게임 진행 개선** 항목.

## 조치 — 버그
| 위치 | 내용 |
|---|---|
| `mafia_ai.py` `clean_llm_dialect` | 분기 안이 `pass`뿐인 죽은 코드(불완전 문장 제거 미구현) 제거 |
| `mafia_ui.py` `_tick_night_loop` | `sec in (15,10,5)`인데 15초엔 아무 메시지도 안 뜨던 조건 정리 |
| `mafia_ui.py` AI 인원 스테퍼 | `winfo_children()` 인덱스로 클릭 재배정하던 취약한 구조 → 진짜 `tk.Button` + 공용 호버로 교체 |
| `mafia_ai.py` `_llm_call` | 네트워크 타임아웃과 인증오류/잘못된 모델명을 구분 못 하던 문제 — `applog`로 원인 기록(사용자에겐 계속 조용히 실패, 로그만 남음) |
| `mafia_config.py` `ROLE_TABLE` | 실제 테이블과 안 맞던 주석 정정, `MIN_PLAYERS_CORE=4`라 절대 안 쓰이던 3명 항목 제거 |
| `mafia_core.py` | `VOTE_FULL_MACHINE`이 상수로 고정된 True라 도달 불가능했던 구 단일개표 경로(`tally_votes`/`execute`) 및 `_tally_and_reveal`의 죽은 분기 제거 |

## 조치 — 게임 진행 개선
- `DAY_CYCLE_SECONDS` 120→150초: 역할 연출·최후변론(60초)·찬반(30초)까지
  겹치면 토론 체감이 빠듯하다는 지적 반영.
- 최후 변론 중 AI 응답이 느리면(LLM 지연) 6초 안전망이 대신 발화한 뒤,
  뒤늦게 도착한 진짜 응답이 또 붙어 "서로 안 맞는 말을 두 번" 하던 문제 —
  안전망이 이미 대신 말했으면 뒤늦은 첫 슬롯 응답은 버리도록 수정(20초/40초
  슬롯은 원래 설계대로 계속 반영).
- 게임 설정창을 열어둔 채 다른 사람이 참가 신청을 해도 AI 인원 상한이
  갱신 안 되던 문제 — 클릭/저장 시점마다 현재 연결 인원 기준으로 다시 계산.
