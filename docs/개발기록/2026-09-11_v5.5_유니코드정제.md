# v5.5 유니코드 이형 문자 선택자(U+FE0F) 폰트 왜곡 방지 및 전구간 살균(Sanitization) (2026-09-11)

- **채팅 입력창 및 말풍선 폰트 크기 불균형/두부 상자 왜곡 원인 분석 (Opus 5 분석 정밀 일치)**:
  - 현상: 특정 텍스트 입력 시 일부 글자가 비정상적으로 커지거나 폰트 모양/줄 높이가 튀고 사각 박스가 생기는 현상.
  - 원인:
    1) Windows 환경의 Tkinter(Tcl/Tk) 텍스트/캔버스 렌더러가 보이지 않는 유니코드 이형 문자 선택자(Variation Selector-16, `U+FE0F`)를 단독 글리프로 오인하여 '맑은 고딕'(10pt, 문자 폭 16px) 대신 시스템 이모지 대체 폰트('Segoe UI Emoji', 폭 22px, 약 1.4배 큼)의 누락 글리프(두부 상자)를 렌더링.
    2) 예: `'김\ufe0f'` 입력 시 맑은 고딕 '김'(16px) 뒤에 22px 크기의 사각 박스가 합성되어 총 38px로 폭과 줄 높이가 비정상적으로 팽창.
    3) UI 버튼/컨텍스트 메뉴 문자열에 포함되어 있던 이모지(✏️ `\u270f\ufe0f`, 👁️ `\U0001f441\ufe0f`, 🗑️ `\U0001f5d1\ufe0f`) 역시 내부적으로 `U+FE0F`를 포함하고 있어 복사/붙여넣기 시 입력창으로 전파될 위험 상존.
- **3단계 전구간 텍스트 살균(Sanitization) 시스템 구축**:
  - `sanitize_chat_text(text)` 함수 신설:
    - Variation Selector 블록(`U+FE00`~`U+FE0F`, `U+E0100`~`U+E01EF`) 필터링.
    - 유니코드 포맷 카테고리 `Cf`(Zero-Width Joiner `U+200D`, Zero-Width Space `U+200B` 등) 및 서로게이트 `Cs` 제거.
    - 제어 문자(`< 32`, 줄바꿈 `\n`과 탭 `\t`은 보존) 제거.
    - 순수 이모지(😊, 👍, 🎉, 🔥 등)는 완벽하게 보존.
  - **1단계: GUI 입력창 실시간 방어**:
    - `<<Paste>>` 이벤트 가로채기(`_on_entry_paste`): 클립보드에서 텍스트를 붙여넣을 때 실시간 살균 후 삽입.
    - `<KeyRelease>` 이벤트(`_entry_resize`): 키보드 타이핑 또는 IME 조합 시 실시간으로 비정상 제어/선택자 문자를 즉시 정제하고 커서 위치 보존.
  - **2단계: 송신/수신/네트워크/디스크 영속화 방어**:
    - 전송 시(`_send`, `Engine.send_message`, `Engine.send_group_message`): 메시지 전송 및 로그 저장 전 살균 처리.
    - 수신 시(`Engine._handle_dict`의 `msg`, `group_msg`): 패킷 수신 즉시 발신자 이름 및 본문 살균.
  - **3단계: 화면 렌더링 방어**:
    - 로그 변환(`_rec_from_raw`) 및 캔버스 말풍선 그리기(`_draw_bubble`): 과거 로그나 외부 비정상 텍스트가 렌더링 파이프라인에 유입되더라도 말풍선 생성 직전에 최종 살균하여 폰트 튐/두부 현상 100% 원천 차단.
  - **UI 버튼/메뉴 텍스트 정제**:
    - 헤더 이름 변경 버튼, 채팅 탭 우클릭 팝업, 대화방 더보기 메뉴의 이모지에서 이형 문자 선택자 제거 (`"✏"`, `"👁"`, `"🗑"`).
