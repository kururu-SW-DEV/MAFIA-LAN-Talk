# v1.02 — 사망자 채팅 차단 + AI 투표 정확도 검증 (2026-09-17)

## 사망자 채팅 차단
- `_mafia_handle_user_text` 맨 앞에 사망 게이트 추가: `alive=False`면 말풍선 추가 없이
  "👻 사망한 참가자는 게임방 채팅을 칠 수 없습니다" 안내만 + 유령 채팅방 자동 오픈
- AI 발화는 이미 `say_async`에서 `pl.alive` 필터로 차단 (기존 기능 그대로)
- AI 투표도 `_ai_vote_in_popup`에서 `pl.alive` 필터로 죽은 AI 제외

## 실측
```
테스터 사망 처리 → 채팅 "안녕 아직 살아있니" 입력
  → system "👻 사망한 참가자는 게임방 채팅을 칠 수 없습니다 — 유령 채팅방에서만 수다"
  → 말풍선 추가 안 됨 (bubble NOT added: True)
```

## AI 투표 정확도 — LLM 직접 실측
- 루카(분석가형 인격) 대상 6회 연속 질의:
```
[1] 3.0s "레오"    [2] 1.2s "테스터"  [3] 1.6s "레오"
[4] 1.2s "레오"    [5] 4.5s "레오"    [6] 1.4s "레오"
형식 준수율: 6/6
```
- 투표 형식("투표 이름") 대응 파서 강화: LLM이 후보 이름만 단답해도
  후보 목록과 일치하면 승인 (`'테스터'` 단답 케이스 통과 — v1.00 응답 기록).
- AI 투표가 core에 실제 반영됨 (`core.cast_vote`).

  실제 후보와 일치하면 수용.
