# v1.51 — 마피아 게임방 상단 메뉴 정리 (2026-09-19)

## 사용자 지적
"마피아 게임 채팅방의 상단의 설정에는 채팅방 이름 지우기랑 채팅방
나가기가 있어. 마피아 게임이 아닌 채팅방에서는 이게 맞는데, 마피아
게임에서는 안나오게 해줘" (이후 정정: "대화 숨기기야 대화나가기가 아니라
정정")

## 원인

채팅방 상단 "⋯" 더보기 메뉴(`_open_room_more_menu`, `app.py`)가 방 종류를
구분하지 않고 모든 항목을 그대로 띄우고 있었다 — 일반 DM/그룹방용 메뉴가
가상 게임룸인 마피아 게임방에도 동일하게 노출됨.

## 조치

마피아 게임방(`self.current[0] == "mgame"`)에서는 다음 항목을 제외:
- 대화방 이름 변경
- 대화 숨기기
- (덤) 대화 기록 삭제 — `engine.delete_history(key)`가 실제 dm/grp 키
  구조를 전제로 하는데 mgame 가상 키에는 의미가 없어 같은 이유로 제외.

다운로드 폴더 관련 3항목(열기/변경/크기 조절)은 게임방에서도 파일 전송에
필요하므로 유지. 사이드바 우클릭 메뉴(`_show_row_menu`)는 이미
`key[0]=="mgame"` 가드가 있어 손댈 필요 없었음.

## 검증

`_popup_menu`를 모킹해 mgame 방과 일반 DM 방 각각에서 실제로 뜨는 메뉴
항목 목록을 캡처해 대조 — mgame은 다운로드 3항목만, DM은 기존 8항목 전부
유지됨을 확인.
