# v6.31 — 스티커 피커 "최근/스티커" 탭 시인성 개선 (2026-09-14)

## 계기

사용자가 스크린샷과 함께 보고: "이거 보면 최근이랑 스티커랑 뭐가 눌렸는지 모르겠어.
시인성 좋게 탭같은 느낌으로 해줘." — 선택된 탭 표시가 글자색(밝음/흐림)만 다르고
배경은 둘 다 동일해 구분이 잘 안 됐다.

## 수정 (`widgets.py`)

`EmojiPicker`의 "최근"/"스티커" 탭 스타일을 사이드바의 "채팅"/"친구" 탭과 완전히
같은 방식(선택된 탭 = `C_ROWSEL` 배경 + 밝은 글자 + 굵은 글씨, 미선택 = 카드
배경 + 흐린 글자)으로 통일했다. 공통 헬퍼 `_style_tabs()`를 새로 만들어 초기화
시점과 `_switch_cat()` 양쪽에서 재사용하도록 정리했고, 미선택 탭에 마우스를
올리면 살짝 밝아지는 호버 효과(`_tab_hover`)도 추가했다(선택된 탭은 호버로 흐려
보이지 않도록 제외).

## 검증

- 실제 앱을 띄우고 두 탭을 각각 선택한 상태로 스크린샷을 찍어(픽셀 색상으로
  앱 창이 맞는지 자체 검증 후) 육안 확인 — 선택된 탭에 뚜렷한 배경 필이 생겨
  한눈에 구분됨.
- `tests/test_gui_flow.py`, `tests/smoke_gui.py` 재실행, 전부 통과.
- `python -m py_compile widgets.py`로 문법 확인.
