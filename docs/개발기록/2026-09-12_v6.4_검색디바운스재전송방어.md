# v6.4 검색창 디바운스 최적화 및 암호화 계층 재전송(Replay) 공격 방어 구현 (2026-09-12)

- **검색창 디바운스(150ms) 및 이벤트 중복 바인딩 정리 (`app.py`)**:
  - `self.search_var.trace_add` 2개와 `self.search.bind("<Any-Key>")` 1개가 중복 등록되어 키보드 타이핑 시마다 `_refresh_list()`와 동기 파일 검색(`search_all_logs`)이 3회씩 메인 GUI 스레드를 점유하던 병목 제거.
  - `self._search_debounce_id`를 도입하여 키 입력 시 이전 대기 타이머를 취소하고 150ms 비활성 후에만 1회 단일 스캔 실행 (`root.after(150, self._refresh_list)`).
  - 탭 전환, 메시지 수신 등 직접 `_refresh_list()`를 호출하는 시점에는 예약된 디바운스 타이머를 안전하게 취소하여 불필요한 중복 렌더링 방지.
- **암호화 계층 재전송(Replay) 공격 방어 탑재 (`crypto_layer.py`)**:
  - V2 패킷 헤더 구조 정의: `magic (1B, 0x02) + ts (8B, uint64 ms) + nonce (12B) + hmac_tag (32B) + ciphertext`.
  - **HMAC 인증 범위 확장**: `magic + ts + nonce + ciphertext` 전체를 HMAC-SHA256으로 서명하여 패킷의 타임스탬프 위변조 원천 방어.
  - **시간 유효성 윈도우 검사**: `MAX_CLOCK_SKEW = 120.0` (2분). 송신자와 수신자 간 시계 오차 허용 범위를 2분으로 제한하고, 2분 초과 과거 패킷 및 비정상 미래 패킷 즉시 폐기.
  - **슬라이딩 윈도우 안티 리플레이 태그 캐시 (`_replay_cache`)**: 120초 유효 창 내에 도착한 패킷이라도 이미 수신 처리된 태그는 중복 거부 (`tag in _replay_cache` 시 `None` 반환).
  - **주기적 캐시 프루닝 (`_prune_replay_cache_locked`)**: 30초 주기로 120초가 지난 캐시 항목을 자동 삭제하여 메모리 점유율을 수십 KB 수준으로 영구 억제.
  - 신뢰 전송 재시도(UDP Retry) 시 매번 새로운 12바이트 무작위 논스와 타임스탬프를 생성하므로 정상 재전송은 암호화 계층에서 정상 복호화되고 앱 레벨 중복 필터링(`_seen_mids`)에서 안전하게 처리됨.
