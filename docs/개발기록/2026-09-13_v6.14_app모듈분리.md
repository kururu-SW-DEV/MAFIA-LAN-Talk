# v6.14 — 대규모 모듈화 리팩토링 (app.py 모듈 분리 및 유지보수성 극대화) (2026-09-13)

### 1. 리팩토링 배경 및 목표
- **배경**: `app.py` 단일 파일이 3,928줄(~187KB)에 달하며 UI 렌더링, 검색, 파일 드래그앤드롭, 30개 이상의 팝업 다이얼로그가 모두 한 클래스(`App`)에 밀집되어 코드 탐색 및 유지보수가 어려운 상태였음.
- **목표**: 기존 외부 API 및 테스트 코드의 완벽한 100% 호환성을 유지하면서, 기능적 도메인별로 믹스인(Mixin) 클래스로 모듈화 분리.
- **아키텍처**: 다중 상속 믹스인 패턴 채택 (`class App(DialogsMixin, ChatRendererMixin, ChatSearchMixin, DndMixin):`).
  - 외부 테스트 및 호출부에서 `app.chat`, `app._reload_chat()`, `app.current` 등 기존 인스턴스 멤버에 접근하는 방식이 100% 동일하게 동작하도록 보장.

### 2. 분리된 모듈 구성
1. **`dnd_handler.py` (`DndMixin`)**:
   - Windows 저수준 `WH_GETMESSAGE` ctypes 훅 기반 드래그 앤 드롭 파일 수신 로직 (`_setup_drag_and_drop`, `_on_files_dropped`).
2. **`chat_search.py` (`ChatSearchMixin`)**:
   - 대화 내 검색 바(Ctrl+F) 제어 및 일치 항목 탐색, 캔버스 스크롤 및 하이라이트 애니메이션 (`_open_search`, `_close_search`, `_on_search_query`, `_on_search_prev`, `_on_search_next`, `_scroll_to_match`, `_flash_highlight`, `_clear_highlight`).
3. **`chat_renderer.py` (`ChatRendererMixin`)**:
   - 채팅 캔버스 동적 리사이즈, 하단 이동 플로팅 버튼, 날짜 구분선, 말풍선 렌더링, 복사, 썸네일 디코딩 및 캐시, 파일 카드, 실패 알림 등 UI 렌더링 엔진 전담 (`_draw_bubble`, `_draw_record`, `_reload_chat`, `_draw_image_bubble`, `_draw_file_card` 등 29개 메서드).
4. **`dialogs.py` (`DialogsMixin`)**:
   - 공통 위젯 헬퍼(`_btn`, `_hover`, `_popup_menu`, `_alert`, `_prompt_text`), 아바타 관리 다이얼로그, 숨긴 대화방 관리, 다운로드 폴더 선택, 그룹 탈퇴, 카테고리 설정, 이름 변경, 대화 기록 삭제, 네트워크 설정, 그룹 생성, 공지 방송, 멤버 초대 등 30개 다이얼로그 전담.
5. **`app.py` (`App` 본체)**:
   - 3,928줄 -> 2,018줄로 약 50% 슬림화. 메인 윈도우 레이아웃 구조화(`_build_shell`), 통합 대화 목록 관리, 이벤트 펌프 루프(`_pump`), 입력창 키보드/멘션 인터랙션(`_layout_input_bar`, `_send`)에 집중.
   - 비동기 검색 결과 전달을 Tkinter 스레드 안전 큐(`self.q`)와 `_pump()` 연동으로 개선하여 백그라운드 스레드 `RuntimeError` 원천 차단.
