# v1.44 — 역할 팝업 글자 잘림 수정 + 게임 시작 시 전체화면(1차) (2026-09-19)

## 사용자 지적
"글자가 잘려 있어. 그리고 마피아 게임은 처음 시작시 전체화면으로 시작되게 해줘"
(스크린샷 첨부 — "[시  민]" 아래 설명 문구가 "그리고 단결된 투표권으로..." 부분에서
잘려 보임)

## 원인 (실측)

역할 안내 팝업(`_show_role_popup`)이 420px 고정폭 패널인데, 안의 긴 문장
라벨들에 `wraplength`가 없어서 패널 폭을 넘는 부분이 화면 밖으로 그냥
잘려나가고 있었다("그리고"가 "1리고"처럼 반쪽만 보이는 것도 같은 원인).
밤/재판/판결 스플래시 배너도 동일한 문제를 갖고 있었다.

## 조치

- `mafia_ui.py`의 역할 설명 라벨, 행동 지침 라벨, 비밀 안내 라벨에
  `wraplength=360~380` 추가.
- 스플래시 배너(`_mafia_show_splash`)의 제목/부제 라벨에도 선제적으로
  `wraplength=400` 추가(긴 이름이 들어갈 때 대비).
- `_mafia_maximize_window()` 신설 — 게임 시작(`_launch_game_with_recruits`)
  시 `root.state("zoomed")`로 창을 최대화(1400x800 고정 크기로 바뀌는
  v1.50 이전 1차 조치).

## 검증

실제 창을 띄워 화면 캡처로 확인 — 모든 문장이 잘리지 않고 온전히 보임.
`state("zoomed")` 호출 시 450x800 → 1920x995로 실제 확장되는 것도 실측 확인.
기존 회귀 테스트(`test_vote_flow.py`, `test_progress_disconnect.py`,
`test_gui_flow.py`) 재확인.
