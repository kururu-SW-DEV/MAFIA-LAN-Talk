# v1.62 — 규칙 점검, AI 대화 확장(비밀방·유령방), LLM 연동 개선, 트레이 아이콘 누수 수정 (2026-09-20)

## 배경
"이 게임의 진행 규칙이 제대로 된 게 맞는가"라는 점검 요청에서 시작해, 플레이 중 나온 불편
(AI 말투, 비밀방/유령방 대화, 말 잘림, Gemini 연결)과 외부 보고서 3건 검증 결과를 한 번에 정리한다.
변경 파일: `mafia_core.py`, `mafia_config.py`, `mafia_ai.py`, `mafia_ui.py`, `winapi.py`, `tests/*`.

## 1. 게임 규칙 점검 (코드 리뷰 → 수정)
표준과 일치하는 부분(진행 순서, 승패 판정, 의사/경찰 판정, 투표·최후변론·찬반, 자투 금지, 사망자 투표권 없음)은
그대로 두고, 어긋난 곳만 고쳤다.

| 항목 | 조치 |
|---|---|
| 첫날 밤 킬 금지 코드(`first_night_done`)가 항상 `True`라 죽은 코드 | 플래그·분기 제거. 동작(첫날 밤부터 정상 살해)은 그대로, 주석과 실제를 일치 |
| 사람 의사는 자기 보호 가능 / AI 의사는 자기 제외 | AI 의사도 자기 보호 허용(연속 같은 대상 보호 금지는 유지) |
| 4~7명 게임에 경찰이 없고 8명부터 배치(4인은 시민 정보력 부재) | `ROLE_TABLE`: 4~10명 모두 **의사 1 + 경찰 1**, 마피아는 4~6명 1 / 7~10명 2 |

배치 결과: 4명 = 마피아1·의사1·경찰1·시민1, 7명 = 마피아2·의사1·경찰1·시민3, 8~10명 = 마피아2·의사1·경찰1·시민4~6.
(4인 게임은 시민이 1명뿐이라 여전히 어렵다. 필요하면 최소 인원을 5로 올리는 방법이 있다.)

## 2. UI/문구
- **마피아 비밀방이 메인 전송 버튼을 가림**: 비밀방과 "🔪 마피아 밀담" 버튼이 창 우하단에 고정돼 메인 전송 버튼과 겹쳤다.
  `_mafia_room_place`로 **메인 전송 버튼 바로 위(우측 정렬)**에 배치(창 크기를 바꿔도 따라감, 전송 버튼이 없으면 옛 위치로 폴백).
- **직업 공개 문구 받침 처리**: "시민였습니다" → "시민이었습니다". `_role_was()`가 받침 유무로 "이었/였"을 고른다
  (마피아였습니다 / 의사였습니다 / 경찰이었습니다 / 시민이었습니다).

## 3. AI 성격·말투 순화
"AI가 까칠하고 논리만 따져 피곤하다"는 피드백 반영.
- `AI_PERSONAS`(항상 먼저 배정되는 기본 5인)를 다정한 친구형·분위기 메이커·유쾌한 구경꾼·뒤끝 없는 열혈형·상냥한 배려형으로 교체.
- `PERSONAS20` 중 탐정놀이·의심병·돌직구·새침이·근자감·메모광·확률맨·반장을 장난스럽고 몰아붙이지 않는 성격으로 순화, 공격성(`att`) 하향.
- 공통 시스템 프롬프트(`mafia_ai.py`)에 말투 지침 추가: 따지는 어투·발표식 논리 나열·조목조목 반박 지양, 의심은 가볍게, 반박당해도 웃으며 받기.

## 4. AI와의 대화 확장
### 4-1. 유령방 티키타카 (로컬 + 원격)
- 원인: `_ghost_send`가 내 말을 화면에 찍기만 하고 AI에 전달하지 않았고, 사망 AI가 없으면 답장 폴러도 시작되지 않았다.
- 수정: 사망 AI 1~2명이 최근 대화 8줄과 내 발언을 보고 직접 답한다. LLM이 바쁘면 3회 재시도 후 기본 맞장구. 사망 AI가 없으면 "대화 상대가 없어요" 안내.
- **원격 사망자**: AI는 호스트에서만 돌아가므로 `ghost_to_ai`(→호스트)로 중계하고, 호스트가 사망 AI의 답을 개인 전송 `ghost_say`로 돌려준다.
  호스트는 **실제 사망한 사람**의 발언만 처리한다(산 사람이 보낸 유령방 말은 무시).

### 4-2. 마피아 비밀방 사람↔AI (기존엔 사람 동료만 지원)
- AI 마피아만 동료여도 비밀방이 열린다(`_mafia_ai_mates`). 사람 1명 + AI 마피아 조합에서도 밤에 의논 가능.
- 사람이 말하면 AI 마피아 1(~2)명이 답한다. 밤 시작 약 4.5초 뒤 AI가 먼저 후보를 제안하며 말을 건다(이미 대화 중이면 생략).
- AI끼리만 이 대화를 기억하고 공개 채팅에는 노출되지 않는다. 밤이 끝난 뒤 도착한 답은 버린다.
- 원격 사람 마피아 → `mafia_to_ai`(→호스트) → 호스트 AI 답 → 개인 전송 `mafia_say`.
- LLM 응답은 큐(`_mafia_ai_q`) + 메인스레드 폴러(`_poll_mafia_ai_queue`)로 반영한다(워커 스레드에서 `root.after` 직접 호출 금지). 워커 예외는 `applog`로 남긴다.

### 4-3. 대화로 정한 살해 목표를 실제 합의에 반영
`_mafia_kill_plan`(`target`, `by`, `confirmed`)으로 관리한다.
- 사람이 대화에서 후보 이름을 말하면 **확정**, AI가 제안한 이름에 "좋아/ㅇㅋ/가자" 등으로 동의하면 그 제안이 확정.
- 사람이 다른 이름을 말하면 사람 결정이 우선, 확정 뒤에는 AI가 다른 이름을 말해도 바뀌지 않는다.
- 목표가 바뀔 때마다 비밀방에 `📌 오늘 밤 목표: ○○ (제안/확정/취소)` 표시.
- **최종 합의 우선순위**(`_reconcile_mafia_night`): 사람이 밤 패널에서 직접 고른 대상 > 대화로 정한 목표(확정/AI 제안) > AI 개별 무작위 지목.
- **이름 파싱**(`_named_split`): 부정 표현이 붙은 이름은 목표로 잡지 않는다.
  - 이름 뒤 부정어("안 돼", "말자", "피하자", "제외", "패스", "건드리지" …) → 부정.
  - 이름 앞 부정어("안 돼 김철수", "별로야 김철수는 진짜")는 뒤에 "노리자/하자/어때" 같은 서술이 없을 때만 부정. 모호한 "아니"는 앞쪽 부정어에서 제외.
  - 긴 이름 우선 매칭으로 `민우`/`정민우` 같은 부분 문자열 충돌 방지.
  - 이미 정한 목표를 "안 돼"라고 하면 취소.

## 5. LLM 연동 개선 (`mafia_ai.py`)
- **말 잘림**: 응답이 `finish_reason=length`(토큰 한도)로 끊겨도 그대로 화면에 올리던 문제. 이제 **한도 4배로 1회 재요청**, 그래도 잘리면
  마지막 완결 문장(`.!?…~ㅋㅎㅠ`)까지만 남긴다(`_trim_to_sentence`). 잘림 발생은 `debug.log`에 `mafia_llm_truncated`로 기록.
- **Gemini(재미나이)**: 주소에 `generativelanguage.googleapis.com`이 있을 때만 `reasoning_effort=low`를 보낸다(생각 토큰이 `max_tokens`를
  잡아먹어 답이 비거나 잘리는 문제 완화). 모델이 옵션을 거절(400)하면 빼고 재시도. vLLM 등 다른 서버에는 보내지 않는다.
- **빈 API 키 로그 왜곡**: 키가 `""`이면 `replace("", "***")`가 글자마다 `***`를 끼워 넣던 것 수정.
- **Gemini 연결 방법(코드 수정 없이 게임 설정의 AI API 카드에 입력)**:
  서버 URL `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`, 모델명 `gemini-3.6-flash`(가벼운 `lite` 계열도 가능), API Key.
  실측: `gemini-2.0-flash`는 종료된 모델이라 404가 나며 Google이 `gemini-3.6-flash`를 안내했다. 모델명은 시기에 따라 바뀌므로 AI Studio 목록으로 확인.
  연결 문제는 `data/debug.log`의 `mafia_llm_call` 줄로 원인(모델명/키/URL)을 구분할 수 있다.

## 7. 트레이 아이콘 누수 수정 (이번 정리)
- **증상**: 작업표시줄 트레이 오버플로에 같은 빨간 아이콘(MAFIA/LAN Talk)이 10개 쌓임.
- **원인**: 정상 종료 경로 `_quit()`은 `_notifier.close()`로 트레이 아이콘을 지우는데(`Shell_NotifyIconW(NIM_DELETE)`),
  **테스트가 App을 만들고 `_quit()` 없이 프로세스만 끝내서** 죽은 아이콘이 남았다(프로세스를 강제 종료해도 동일). 테스트를 반복 실행한 만큼 쌓임.
- **수정**:
  - `winapi.py`의 `Notifier`가 아이콘 추가 성공 시 `atexit.register(self.close)`로 안전망 등록(예외 종료 등으로 `_quit`을 못 거쳐도 파이썬 종료 시 제거, `close`는 중복 호출 안전).
  - App을 만드는 테스트 5개(`test_gui_flow`, `test_progress_disconnect`, `test_vote_flow`, `test_multiplayer_sync`, `smoke_gui`)의 종료부에서 `_notifier.close()` 호출.
- **검증**: 오버플로 트레이 아이콘 수를 직접 세어(`TB_BUTTONCOUNT`) 테스트 4~7회를 돌린 뒤에도 늘지 않음(6개 유지).
- **이미 쌓인 죽은 아이콘 정리**: 트레이 툴바에 마우스 이동 메시지를 보내면(`WM_MOUSEMOVE`) Windows가 죽은 아이콘을 지운다. 위 오류 이전에 남은 것은
  트레이에서 마우스를 훑거나 탐색기를 재시작해도 없어진다.
- 주의: 테스트를 강제 종료(`kill -9`, 타임아웃 종료)하면 `atexit`도 실행되지 않아 아이콘이 다시 남을 수 있다.

  대화 목표 확정·동의·사람 우선·밤 패널 우선·원격 확정, 최후 변론 원격 전달, 원격 유령방 중계(상대 없음 안내·사망자 답장·생존자 무시), 끊김 문구.
- **불안정(플레이키)의 진짜 원인 3가지** — 제품 결함이 아니라 테스트 환경 문제였다.
  1. 게임 시작 때 무작위로 배정된 **다른 AI의 마피아 역할**이 남아 있으면(약 40%) 그 AI가 대신 답해 `ai_m` 답장을 기다리는 검사가 실패 → 다른 AI를 시민으로 고정.
  2. 긴 테스트 도중 호스트의 **접속 끊김 감시기**가 원격 B를 사망 처리해 게임이 끝남 → 사람↔AI 구간 동안만 감시기를 멈췄다가 ⑥ 직전에 되살림.
  3. **같은 폴더에서 다른 곳이 동시에 테스트를 돌리면 포트(60031/60032 등)가 겹쳐** 출력 없이 실패. 실행 전 `python` 프로세스가 없는지 확인.
- 실행 시 한글 콘솔 인코딩 오류(`cp949`)를 피하려면 `PYTHONIOENCODING=utf-8`.
- 전체 스위트(`test_headless`, `test_gui_flow`, `test_vote_flow`, `test_night_chatter`, `test_progress_disconnect`, `test_ai_banter`, `test_ai_pile_on`,
  `test_multiplayer_sync`, `test_report_fixes`, `smoke_gui`) 통과.

## 알려진 한계·보류 결정
- **인간 마피아 둘이 갈릴 때**: 지금은 먼저 고른 사람의 선택이 팀 결정(살해가 자주 무산되는 것을 피하려는 v1.61 설계). 규칙 원칙(갈리면 무효)으로 바꿀지는 미정 —
  바꾸면 갈릴 때 "의견이 갈려 무산" 안내를 함께 넣는다.
- **경찰 결과 안내 문구**: 역할 팝업에는 "다음 날 아침 보고"라고 적혀 있으나 실제로는 선택 즉시 통보(+호스트가 경찰이면 아침에 한 번 더). 문구를 "선택 즉시 알려 드립니다"로 맞추는 편이 좋다.
