# v1.23 — 최후변론 60초 변론 기간 (AI 피고인 포함) (2026-09-18)

## 사용자 지적 2건
1. "최후 변론 기회 없이 바로 처형여부 투표로 가고"
2. "변론 기회는 60초를 부여해야지"
3. "AI여도 변론 기회 60초야"

## 원인

기존은 변론 LLM 응답 1건이 채팅에 뜨자마자 찬반 팝업+AI 찬반 표가 개시됨 —
변론을 '하나 보여주고 끝'으로 처리해 기회라는 체감이 없음.

## 조치 (v1.23) — 변론 기간 60초 제도화

| 항목 | 내용 |
|---|---|
| 변론 기간 60초 | AI 피고인도 **60초 변론 기간** — 0.5초/20초/40초 시점에 3번 분할 발화(LLM) |
| 유저 피고인 | 60초 동안 직접 채팅으로 변론 (기존 그대로) |
| 찬반 개시 | 변론 기간 종료(60초) 후 "⚖ 변론 종료 — 찬반 투표 (30초 이내)" 안내 → 찬반 팝업 개시 + AI 표 투입 |
| 찬반 안전망 | 변론 종료 후 30초 → 총 90초 예산(60 변론 + 30 찬반) |
| 사회자 안내 | "⚖ 'OO' 님이 최다 득표로 최후 변론대에 섰습니다. (60초)" / "⚖ 최후 변론(60초): 피고인만 변론합니다. 이후 찬반 투표(30초)." |
| 폴백 유지 | 변론 LLM이 6초 내 무응답 → 기본 변론문 투입(팝업 개시 방지) |

## 실측 (E2E)

```
개표 → 피고인 김과장 → 사회자 안내 60초 변론 선고
→ AI 피고인 변론 1회 발화(0.5초 시점) 렌더
→ 찬반 개시 타이머(_defense_end_timer 60s) + 찬반 안전망(90s) 등록 확인
→ 60초 후(실사) 찬반 팝업 개시 예정
```

컴파일 OK, 배포 30.05MB, 스모크 PASS.

```

② AI 피고인 변론 발화 — 채팅 말풍선 렌더 (0.5초 시점 1회 관측, 20s/40s 스케줄 등록)

⑤ 집계 — "⚖ 찬성 1 : 반대 2 — 처형 부결, '김과장' 님은 살아남았습니다." 렌더
```
