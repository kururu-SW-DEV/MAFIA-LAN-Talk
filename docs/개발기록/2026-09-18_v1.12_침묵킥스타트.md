# v1.12 — 유저 침묵 시 AI 자율 발화 킥스타트 (2026-09-18)

## 사용자 지적
"내가 말을 안하면 AI들이 말을 안해"

## 원인 (실측 확정)

**AI 발화가 전부 '반응형'만 존재** — 유저 발언 이벤트나 다른 AI 발언 체인만
트리거로 사용. 유저가 침묵하면:
- AI 역시 서로도 아무 말 안 하면 트리거가 자동 발생하지 않고,
- 사회자 질문도 없음 → 게임이 낮 타이머 120초 동안 정지 상태처럼 느껴짐.

## 조치 (v1.12)

| 항목 | 내용 |
|---|---|
| 침묵 감지 | `_day_tick_loop`에서 마지막 발화(AI/유저/사회자)로부터 25초 경과 시 킥스타트. |
| 발화 기준점 | `add_mafia_bubble`에서 `_last_any_talk_ts` 갱신 — 유저/AI 발화마다 리셋. |
| 킥스타트 발화 | `_kick_silent_room` 신설 — 살아있는 AI 전원(honor_freq=False)에 "먼저 입을 열어" 프롬프트. freq 제한 해제로 반드시 누군가 말함. |
| 자동 체인 | 낮 타이머 tick loop에 25초 간격 자동 트리거 — 유저가 안 불러도 25초마다 재시도. |
