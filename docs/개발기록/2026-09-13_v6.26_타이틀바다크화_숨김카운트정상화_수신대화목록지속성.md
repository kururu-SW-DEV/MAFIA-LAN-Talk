# 윈도우 타이틀바 다크화, 숨긴 대화 복원/카운트 정상화, 수신 대화 지속성 및 최신순 정렬 (v6.26)

요청하신 3가지 핵심 문제에 대한 원인 분석과 수정, 검증이 모두 완료되었습니다.

---

## 1. 윈도우 타이틀바 다크 테마 일치 및 시인성 개선
- **원인**:
  - Windows 10(Build 19045) 환경에서 Tkinter 창 매핑 초기에는 DWM 다크 속성이 최상위 창 프레임에 제때 전달되지 못하거나, 속성 변경 후 프레임 갱신(`SWP_FRAMECHANGED`)이 호출되지 않아 타이틀바가 밝은 흰색 기본값으로 유지되는 현상이 있었습니다.
- **수정 내용** (`winapi.py`):
  - `user32.GetAncestor(hwnd, GA_ROOT)`를 통해 윈도우 캡션을 직접 제어하는 최상위 프레임 HWND를 확실하게 획득.
  - `DWMWA_USE_IMMERSIVE_DARK_MODE` (20 / 레거시 19), `DWMWA_CAPTION_COLOR` (35), `DWMWA_TEXT_COLOR` (36) 적용.
  - `user32.SetWindowPos(h, None, 0, 0, 0, 0, 0x0037)` (`SWP_FRAMECHANGED`)를 호출하여 프레임 캐시를 즉각 무효화하고 다크 테마로 강제 재렌더링.
  - 창 매핑 시점을 정확히 포착하는 `<Map>` 이벤트 핸들러 바인딩 및 다중 비동기 타이머(`30ms`, `100ms`, `300ms`, `600ms`) 적용.

## 2. 숨긴 대화 복원 시 카운트 정상 감소 및 중복 생성 버그 해결
- **원인**:
  - 메뉴 버튼 라벨의 카운트가 유효 키 개수가 아닌 원시 `len(self.engine.hidden)`을 참조하고 있었습니다.
  - 과거 테스트 과정에서 생성되었던 60개의 더미 "테스트그룹"이 `hidden`에 등록되어 고아(Orphan) 유령 키로 누적되어 있었습니다.
  - `leave_group()`과 `delete_history()`에서 불필요하게 `hide_key()`를 호출하여 나간 방이나 지운 방이 숨김 목록에 계속 누적되었습니다.
  - `_open_hidden_dialog()`에 싱글톤 가드가 없어 클릭할 때마다 창이 중복 생성되었습니다.
- **수정 내용** (`app.py`, `dialogs.py`, `engine.py`, `data/`):
  - `_open_add_menu()`에서 실제 복원 가능한 유효 키 개수인 `len(self._hidden_conv_keys())`를 기준으로 라벨 표시.
  - `_hidden_conv_keys()`에서 나간 그룹이나 존재하지 않는 고아 그룹 키를 감지하여 `self.engine.hidden`에서 영구 자동 삭제 및 저장.
  - `leave_group()`에서 `hide_key` 호출을 제거하고 `hidden.discard()`로 변경; `delete_history()`에서 무단 숨김 처리 제거.
  - `_open_hidden_dialog()`에 싱글톤 창 가드(`self._hidden_win`)를 추가하여 이미 창이 열려 있으면 포커스만 이동.
  - `data/groups.json` 및 `data/settings.json` 내 더미 테스트 그룹(60개) 및 유령 숨김 키를 완전 소거하여 깨끗한 상태로 정리.

## 3. 상대방 호출/메시지 수신 시 대화 목록 보존 및 최신순 정렬
- **원인**:
  - `engine.py`의 `_prune()`이 2초마다 실행되며, 정적 등록(`static`)이 아닌 동적 피어가 15초 동안 브로드캐스트가 없으면 `del self.peers[key]`로 삭제해 버렸습니다. 이로 인해 유니캐스트로 먼저 말을 건 상대방이 15초 뒤 대화 목록에서 사라졌습니다.
  - 앱 재기동 시 디스크에 기존 1:1 대화 로그(`.jsonl`)가 남아있어도 `self.peers`에 로드되지 않아 대화 목록에 누락되었습니다.
  - 대화 탭 목록이 최근 메시지 시각이 아닌 단순 이름 가나다순으로 정렬되어 있어, 이름이 뒤쪽인 상대방에게서 메시지가 와도 스크롤 아래쪽으로 밀려 보이지 않았습니다.
- **수정 내용** (`engine.py`, `app.py`):
  - **대화 기록 보존 (`_prune`)**: `_prune()` 실행 시 디스크에 1:1 대화 로그 파일(`self._log_path(ip, port)`)이 존재하는 상대는 `self.peers`에서 삭제하지 않고 오프라인 상태로 안전하게 보존.
  - **재기동 시 과거 대화 피어 자동 복원 (`_load_history_peers`)**: 엔진 기동 시 `logdir` 내 대화 로그 파일들을 스캔하여 `self.peers`에 즉시 등록.
  - **대화 탭 최신순 정렬 (`sort_key`)**:
    - 1순위: 읽지 않은 메시지(`unread > 0`) 수신 대화방 최상단 배치.
    - 2순위: 최근 메시지 발송/수신 시각 최신순 (`-last_ts`, O(1) 초고속 캐시).
    - 3순위: 이름 가나다순.
    - 상대방이 메시지를 보내면 즉시 목록 맨 위로 올라오도록 개선.
  - **채팅 탭 버튼 읽지 않음 배지 표시**: 읽지 않은 메시지가 존재할 때 좌측 탭 버튼에 `채팅 (N)` 형식으로 실시간 배지 표시.
