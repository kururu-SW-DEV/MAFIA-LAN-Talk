# v4.3 티타늄 그레이 다크 테마 + 9:16 창 비율 + 호버링 버그 수정 (2026-09-11)

- **친구/대화 목록 행 호버 깜빡임(되다 마는 현상) 근본 수정**:
  기존에는 `row.bind("<Enter>")` 및 `<Leave>`가 부모 프레임에만 걸려 있어, 마우스 커서가 행 안의 자식 위젯(아바타 캔버스, 이름 라벨, 미리보기 라벨 등) 위로 진입하면 부모 프레임 입장에서 `<Leave>` 이벤트가 발생하여 호버 배경이 즉시 해제되거나 깜빡거렸다.
  `row`, `av`, `mid`, `name_lbl`, `prev_lbl`, `right`, `badge` 등 행 내 모든 구성 요소에 호버 이벤트를 바인딩하고, `<Leave>` 시 `row.winfo_containing(e.x_root, e.y_root)`로 마우스가 여전히 해당 행 내부 위젯에 머물러 있는지를 검사하여 자식 간 이동 시 호버가 조기 해제되지 않도록 해결.
- **기본 창 크기 9:16 비율(450×800) 및 최소 크기(`minsize`) 축소**:
  기존 `1120x700`, `minsize(940, 600)`으로 창을 작게 줄일 수 없었던 제약을 해소. 기본 크기를 스마트폰/데스크톱 메신저 표준 세로 비율인 `450x800` (9:16)으로 변경하고, `minsize(360, 540)`으로 축소하여 사용자가 원하는 만큼 작게 줄여서 화면 구석에 배치할 수 있도록 개선. `<Configure>` 이벤트를 통해 창 크기 변경 시 사이드바 너비를 유연하게 조절.
