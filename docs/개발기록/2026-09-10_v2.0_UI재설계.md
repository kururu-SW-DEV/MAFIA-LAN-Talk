# v2.0 UI 재설계 (2026-09-10)

- 사용자 피드백 "디자인이 너무 유치한데" → GUI 레이어를 상용 메신저 구성으로 통째로 교체.
  **네트워크 엔진(Engine)은 1줄도 손대지 않음** — 검증된 계층 보존 원칙.
- 새 구성: 좌측 사이드바(내 프로필 카드·이름 변경 링크·검색창·목록 헤더·대화 행=원형 아바타/
  이니셜/온라인 점/미리보기/읽지 않음 배지), 우측 채팅(헤더=상대명·IP:포트·접속 상태,
  말풍선 본문, 입력창+전송 버튼), 하단 상태줄.
- 색 체계: 창·패널 화이트, 배경 연회색(#f4f5f7), 내 말풍선 인디고(#5b62e0), 상대 흰색,
  배지 레드(#e53935), 온라인 그린(#3fb760). 폰트 맑은 고딕 체계 6단계.
- 렌더 방식: 채팅은 Tk Text 태그 기반. 이번 재설계에서 배운 Tk 사실 2건:
  1) 말풍선 태그가 개행(\n)까지 포함되면 배경이 라인 전체로 늘어나 "흰 바"가 된다 →
     태그를 본문 문자에만 걸고 개행은 태그 없이 삽입해야 내용 폭 말풍선이 된다.
  2) Text는 항상 top-anchor라 콘텐츠가 뷰포트보다 짧으면 위에서부터 쌓인다 →
     콘텐츠 앞에 빈 줄 패드(26-2n, 최대 30줄)를 넣고 see("end")로 스크롤해
     "메시지가 입력창 위에 붙는" 카톡식 배치를 구현.
- 말풍선 그룹핑: 같은 발신자+같은 분 = 라벨 생략·스택, 바뀌면 라벨 1회 + 간격 광고.
  시간 표기는 분 단위(오후 8:42), 내 메시지 시간은 우측 회색.
- 발견된 버그 v2에서 잡은 것: `_date_tag`가 state를 normal로 두고 복구하지 않아
  이후 insert가 무시됨(채팅이 빈 화면처럼 보이는 원인) → 인라인 처리로 해결.
- 검증: headless/GUI flow/스모크 3종 전부 통과(exit 0), py_compile OK, 렌더 구조 실측
  (peer/mine 태그 구간에 개행 미포함, dlineinfo로 mine 라인 x+w≈컨테이너 우측=우측 정렬 유지).
- 참고: 스크린샷 기반 시각 리뷰 중 화면 절전·잠금으로 캡처가 검정 화면이 되는 사례 확인 —
  프로그램 문제가 아님. 시각 판정은 사용자 실제 실행 화면으로 최종 확인 권장.
