# v1.13 — 실제 사람 초대 방법 안내 (2026-09-18)

## 사용자 지적
"이 채팅방에 실제 사람은 어떻게 초대해?"

## 현재 구조 (실측 확정)

사람 참가자는 랜톡 6.48 표준 P2P 접속 경로를 그대로 사용:
- 같은 네트워크 구역(동일 사무실 LAN) → **프로그램 실행 시 자동 연결됩니다.**
- 다른 네트워크 구역 → ⚙ 대화방 설정 → **'상대 연결'에서 IP(IP:포트) 수동 등록.**
- 등록된 상대는 `engine.peers`에 등장 → [게임 시작] 클릭 시
  `core.join(상대이름, is_ai=False)`로 게임 참가자에 자동 포함.

다른 네트워크의 상대는 상단 ⚙ 대화방 설정 → '상대 연결' 창에서
