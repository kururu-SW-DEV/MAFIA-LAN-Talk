## 실측 결과

### 경찰 8인 배분
```
alloc 8: ['citizen', 'citizen', 'citizen', 'mafia', 'police', 'citizen', 'doctor', 'mafia']
police: P5
invest mafia: 'mafia'   (정상)
invest citizen: 'citizen' (정상)
re-invest same: 같은 결과 재사용 (중복 조사 방지)
self-invest: None (자기 자신 조사 거부)
```

### 첫날 밤 킬 금지 + 연속 보호 금지
```
첫날 밤 (마피아 지목+의사 보호했지만) victim: None  ← 킬 무효
의사 연속 보호(같은 대상 두 번째 밤): False  ← 금지
다른 대상 보호: True
경찰 중복 조사: 같은 결과(매 조사 소모 없음)
```

### 투표 상태머신 (단독 최다 → 최후 변론 → 찬반)
```
defendant: '테스터'
찬반 투표(피고인 제외) → result='executed', yes=4, no=0 → 처형 확정
기권: OK (abstains 집합 반영)
```

### 사이클 무결성 재확인
```
밤 3초 단축 설정 → 아침 전환 (phase='day', day_no=2)
```
