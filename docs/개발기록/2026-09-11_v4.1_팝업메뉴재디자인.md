# v4.1 팝업·우클릭 메뉴 재디자인 (2026-09-11)

- 계기: 사용자가 "팝업창이랑 우클릭 메뉴가 촌스럽다"고 지적. 원인은 `tk.Menu`(OS 기본 회색 메뉴)와
  `messagebox.showinfo/warning/error`·`simpledialog.askstring`(전부 Tk 기본 회색 대화상자)를 그대로
  쓰고 있었던 것 — 나머지 UI는 이미 텔레그램풍으로 재설계됐는데 이 부분만 옛날 Tk 기본 테마로
  남아 있었다.
- `tk.Menu` 두 곳("＋" 드롭다운, 목록 행 우클릭 메뉴)을 전부 걷어내고, 테두리 없는 `Toplevel`
  (`overrideredirect(True)`) + `Label` 행으로 만든 `_popup_menu(x, y, items)`로 교체. 앱 색상
  (`C_CARD`/`C_HOVER`/`C_SEPAR`)과 폰트를 그대로 쓰고, 포커스 아웃/Escape 시 스스로 닫히게 구현.
- `messagebox.*`·`simpledialog.askstring` 전체 호출부(10곳)를 `_alert(title, message, kind)`·
  `_prompt_text(title, message, initial)` 커스텀 다이얼로그로 교체 — 컬러 점(파랑/주황/빨강)과
  아이콘 글리프로 info/warning/error를 구분하고, 버튼도 기존 `_btn` 헬퍼를 그대로 재사용해 앱
  전체와 일관된 룩을 갖췄다. `messagebox` import는 더 이상 쓰이지 않아 제거.
- 기존 4개 커스텀 다이얼로그(상대 연결/새 그룹 만들기/멤버 추가/멤버 보기)의 체크박스도
  `activebackground`/`highlightthickness=0` 등을 정리해 더 깔끔하게 다듬음.
- 검증: 스크린샷으로 실제 렌더 확인(픽셀 샘플링으로 앱 고유 팔레트가 나오는지 자체 검증 후 사용자에게
  전달 — 화면 캡처 좌표/포커스 문제로 엉뚱한 창을 잡을 때가 있어, 매번 팔레트 매치율을 계산해 이상하면
  버리고 재시도하는 방식으로 확인). "＋" 메뉴·행 우클릭 메뉴·상대 연결 다이얼로그는 실제 스크린샷으로
  확인 완료. `_alert`/`_prompt_text`는 같은 스타일 요소(`_btn`, 색상 상수)를 재사용하는 것으로 코드
  일관성은 확인했으나, 캡처 시도 중 엉뚱한 창(브라우저)이 잡혀 즉시 폐기 — 실제 화면은 미확인 상태로
  사용자 확인 필요. 3종 무인 테스트(헤드리스 3회·GUI 플로우 5회·스모크 3회) 전부 회귀 없이 통과.
