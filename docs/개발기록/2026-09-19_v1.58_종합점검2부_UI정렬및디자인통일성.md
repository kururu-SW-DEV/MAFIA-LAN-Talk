# v1.58 — 종합 점검 2부: UI 정렬 + 디자인 통일성 (2026-09-19)

## 사용자 지적
v1.56과 동일 감사 결과에 대한 "전부다" 수정 지시 중 UI 정렬·디자인 통일성
항목.

## 조치 — UI 정렬(버튼 가운데 정렬 등)

- **후보 버튼 3열 그리드**(투표/재투표/밤 행동/경찰 조사 팝업 4곳): 생존자
  수가 3의 배수가 아니면 마지막 줄이 왼쪽으로 붕 떠 보이던 문제 — 공용
  헬퍼 `_grid_candidates_centered()`를 새로 만들어 4곳 모두 적용. 꽉 찬
  줄까지는 기존처럼 그리드로 늘려 채우고, 남는 마지막 줄만 별도 프레임으로
  빼서 가운데 정렬.
- **설정창 저장/취소 버튼**: `padx=(6,0)`이 취소 버튼의 '왼쪽'에 붙어서,
  정작 저장·취소 버튼 사이는 0px로 서로 붙어 보이던 버그 — 두 버튼
  사이에 실제로 여백이 생기도록 수정(`padx=(0,8)`, dialogs.py의 기존
  확인/취소 쌍 관례와 통일).
- **역할 팝업 확인 버튼**: 이 팝업만 유일하게 `fill="x"`로 폭 100%였던
  것을, 다른 팝업들과 동일하게 자동 크기·가운데 정렬로 통일.
- AI 인원 스테퍼(−/+): v1.56에서 진짜 버튼으로 교체하며 시각적으로도
  다른 버튼들과 통일된 스타일(호버 효과 포함)이 됨.

## 조치 — 디자인 통일성

- **역할 아이콘/한글명 중복 정의 제거**: 역할 팝업(META)과 상단 바
  "내 직업" 버튼에 각각 따로 있던 아이콘·한글명 매핑을 `ROLE_ICON`/
  `ROLE_LABEL_KR` 단일 출처로 통일(총 4곳). 게임 종료 시 정체 공개
  메시지의 역할명 매핑도 같은 소스로 통일.
- **색상 하드코딩 정리**: 가장 많이 반복되던 4가지 색을 이름 붙은 상수로
  추출 — `M_HOST`(보라, 기존 상수 재사용, 9곳), `M_BTN_BG`(후보 버튼
  배경, 7곳), `M_INPUT_BG`(어두운 입력창 배경, 5곳), `M_TEXT_LIGHT`(밝은
  본문 텍스트, 9곳). 값 자체는 그대로라 시각적 변화는 없고, 한 곳만
  바꾸면 전체가 같이 바뀌는 구조로 전환.
- **폰트 크기 파편화 정리**: 가장 자주 쓰이던 4가지 폰트 조합
  (9pt/10pt/10pt굵게/11pt굵게, 총 27곳)에 `M_FONT_HELP`/`M_FONT_BODY`/
  `M_FONT_BODY_B`/`M_FONT_EMPH_B` 이름을 붙여 통일. 1~2곳뿐인 1회성
  강조 크기(제목용 14~32pt 등)는 그대로 둠.
- **패널 여백 통일**: 밤 행동/경찰 조사 팝업의 후보 버튼 줄 여백을
  14px→18px로, 투표 팝업과 동일하게 맞춤.
- 부수적으로 `_show_night_panel`의 "이미 조사" 라벨 들여쓰기 오류도 같이
  정리.

## 참고
색상 124곳/폰트 29곳 전체를 단일 값으로 강제 통일하는 것은 팝업마다 실제
렌더링을 다 확인하지 않고는 회귀 위험이 커서, 가장 반복이 많고 안전하게
검증 가능한 항목 위주로 처리했다. 전면 재설계 수준의 통일이 필요하면
추가 요청 바람.

## 검증

`python -m py_compile` 통과, 기존 회귀 테스트 3종 재확인. 4개 후보(3열
초과) 투표 팝업, 설정창, 역할 팝업을 실제 창으로 띄워 스크린샷으로
가운데 정렬·버튼 간격·스타일 통일을 직접 확인(사용자에게 전달).
