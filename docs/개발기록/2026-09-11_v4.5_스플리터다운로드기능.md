# v4.5 좌측 탭 분할 기둥(스플리터) 드래그 조절/접기 핸들 + 채팅방 다운로드 기능 (2026-09-11)

- **좌측 탭과 대화창 사이의 분할 기둥(스플리터 바) 및 드래그 크기 조절/접기 핸들 구현**:
  - 상단 버튼 대신 좌측 탭(`side`)과 채팅창(`body`) 사이에 세로 분할 기둥(`splitter`, 두께 5px, 커서 `sb_h_double_arrow`)을 배치하여 마우스 드래그로 사이드바 너비를 직관적으로 조절(130px ~ 화면의 60%)할 수 있도록 개선.
  - 마우스 호버 시 기둥이 티타늄 블루(`C_ME`)로 하이라이트되어 조절 가능 여부를 명확히 피드백.
  - 기둥을 왼쪽 끝(< 70px)으로 밀면 자석처럼 자동으로 접히며, 숨김 상태에서 기둥을 오른쪽으로 드래그하면 즉시 다시 펼쳐짐.
  - 기둥 정중앙에 플로팅 접기 핸들 버튼(`self.splitter_btn`, `◀` / `▶`)을 부착:
    - 사이드바 표시 시: `◀` 표시, 클릭 시 사이드바가 접히고 기둥이 창 좌측 끝에 밀착.
    - 사이드바 숨김 시: `▶` 표시, 클릭 시 기억된 이전 너비로 즉각 복원.
  - 단축키 `Ctrl+B` 및 `F4`도 그대로 연동되어 키보드로도 여닫을 수 있음.
- **채팅방 내 다운로드 폴더 설정 & 다른 이름으로 저장**:
  - 채팅방 상단 헤더 우측에 `[📁 다운로드]` 버튼 추가: 클릭 시 드롭다운 팝업에서 '다운로드 폴더 열기' 및 '다운로드 폴더 변경...'을 바로 실행할 수 있도록 지원.
  - 채팅창 내 파일 카드 및 이미지에 우클릭(`<Button-3>`) 시 팝업 메뉴 바인딩:
    1) `열기` (`os.startfile`)
    2) `폴더에서 보기` (`explorer /select,path`로 파일이 위치한 폴더 열기 및 선택)
    3) `다른 이름으로 저장...` (`filedialog.asksaveasfilename`으로 사용자가 원하는 폴더/파일명으로 즉시 복사 저장)
    4) `다운로드 폴더 설정...`
  - 파일 카드 우측에 `💾` (저장) 퀵 버튼 추가: 클릭 시 즉시 `다른 이름으로 저장` 대화상자가 열림.
