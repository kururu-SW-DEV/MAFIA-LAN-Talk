# v1.08 — 밤 AI 행동 즉시 결정 + 밤 채팅 UX (2026-09-18)

## 사용자 지적
"밤에 AI들이 채팅을 안치고, 마피아가 대상자를 안죽여 의사도 활동 안하는듯 하고"
(이전 지적) "최후변론시 대상자가 채팅을 안치" — 병행 수정 포함.

## 원인 (실측 확정)

1. **AI 밤 행동이 LLM을 기다렸음** — `_trigger_night_actions` 워커 스레드에서
   마피아→경찰→의사 순서로 `pl.say()`(LLM 2~5초)를 순차 실행. LLM이 sporadic
   None이면 **해당 밤 행동이 아예 접수되지 않음** → "마피아가 죽이지 않음"
   "의사도 활동 안 함" 처럼 보임.
2. **밤에 AI 채팅이 없는 것** — 밤은 행동 접수만 하고 채팅이 전혀 없어 재미 없음.
3. **최후 변론 LLM 동기 블록** — `_ai_defense`가 메인스레드에서 say(2~5초) 동기
   호출 → UI 프리즈 + LLM 실패 시 변론 말풍선 미출력.

## 조치 (v1.08)

| 항목 | 내용 |
|---|---|
| AI 밤 행동 즉시 결정 | LLM 대기 제거 — 인격 기반 즉시 결정(마피아 살해/경찰 조사/의사 구조 각각 살아있는 생존자 중 무작위). 밤 30초 내 반드시 접수 보장. |
| 밤 AI 채팅 | `_ai_night_chatter` — 밤 20초에 AI 1~2명의 무해 잡담(역할 노출 없음) 추가. |
| 최후 변론 AI 비동기화 | `_ai_defense` 워커 스레드로 이전 — 메인스레드 블록 제거, LLM 실패 시 1회 재시도 후 인격 기본 변론문 출력. |
| 유저 투표 버튼 즉시 개표 | `_popup_vote`에서 all_voted → 0.3초 뒤 즉시 개표(카운트다운 대기 제거). |
| AI 투표 환각 정정 | `_ai_parse_and_vote` — 명단 밖 이름 투표 무효 시 alive 후보 재결정. |
