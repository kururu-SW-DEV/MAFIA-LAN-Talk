# v4.4 Windows DWM 다크 타이틀바 & 상단 디자인 통일 (2026-09-11)

- **창 상단 제목 표시줄(최소화/전체화면/닫기 버튼) 이질감 해결**:
  앱 본체는 티타늄 그레이 다크 테마가 적용되었으나, Windows 기본 창 제목 표시줄(Title Bar)이 밝은 흰색으로 남아 있어 상단 컨트롤 버튼(최소화 `—`, 전체화면/최대화 `▢`, 닫기 `✕`)과의 시각적 괴리(통일감 결여)가 발생했다.
  Python 표준 라이브러리 `ctypes`를 통해 Windows DWM API(`DwmSetWindowAttribute`)를 호출하는 `apply_dark_titlebar(win, bg_hex, text_hex)` 헬퍼를 추가:
  - `DWMWA_USE_IMMERSIVE_DARK_MODE` (20 / 레거시 19): 시스템 타이틀바와 윈도우 컨트롤 버튼을 다크 모드로 전환 (버튼 아이콘이 화이트로 바뀌며 마우스오버 시 다크 하이라이트/닫기 레드 효과).
  - `DWMWA_CAPTION_COLOR` (35): Windows 11에서 타이틀바 배경색을 앱 사이드바 색상(`C_SIDEBAR` #1c1d21)으로 완전 일치.
  - `DWMWA_TEXT_COLOR` (36): 타이틀바 텍스트 색상을 `C_TEXT` (#f3f4f6)로 일치.
  - 메인 윈도우(`self.root`)뿐만 아니라 모든 대화상자(`_alert`, `_prompt_text`, `_settings_dialog`, `_group_create_dialog`, `_group_add_member_dialog`, `_open_member_dialog` 등 `Toplevel`)에도 동일하게 적용하여 앱 전체의 디자인 일관성을 확보.
  - 창 크기 조절 테두리, 에어로 스냅, Windows 11 스냅 레이아웃 가이드, 작업표시줄 애니메이션 등 OS 네이티브 동작을 100% 온전하게 보존.
- 검증: `smoke_gui.py`, `test_headless.py`, `test_gui_flow.py` 전 테스트 무인 통과.
