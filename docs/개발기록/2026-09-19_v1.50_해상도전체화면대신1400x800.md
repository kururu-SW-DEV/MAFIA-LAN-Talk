# v1.50 — 마피아 게임 해상도: 전체화면 대신 1400x800 고정 (2026-09-19)

## 사용자 지적
"현재 열린 마피아 게임 창의 해상도가 뭐야?" (확인 질문 — 당시 실행 중이던
창은 1452x845/클라이언트 1434x800, 모니터 1920x1080이었음, Win32
GetWindowRect로 직접 조회) 이어서:
"앞으로 마피아 게임의 기본 해상도는 기존의 9:16 비율이 아니라 1400:800
비율의 해상도로 설정해줘"

## 조치

`_mafia_maximize_window()`를 v1.44의 `root.state("zoomed")`(전체화면 최대화)
대신, 화면 정중앙에 **1400x800 고정 크기**로 띄우도록 변경. 이미 최대화
상태였다면 `state("normal")`로 먼저 풀고 `geometry()`를 적용.

## 검증

`app._mafia_maximize_window()` 호출 전후 `root.winfo_width/height()`로
450x800 → 1400x800 전환 실측 확인.
