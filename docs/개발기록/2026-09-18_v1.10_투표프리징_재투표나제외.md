# v1.10 — 유저 투표 프리징 체감 배제 + 재투표 후보 '나' 제외 (2026-09-18)

## 사용자 지적
"내가 투표하면 프로그램이 프리징 돼 그리고 재투표시 내가 포함돼"

## 원인 (실측 확정)

1. **투표 접수 후 팝업(overlay)이 닫히지 않음** — `_popup_vote`가 표만 접수하고
   투표 팝업을 그대로 열어둠 → 버튼은 전부 잠기고(min 15초 카운트다운 대기)
   다른 UI를 못 누르는 "프리징" 체감.
2. **재투표 팝업 후보에 '나(유저)' 포함** — `_open_revote_popup(tied)`가
   tied 목록을 그대로 버튼으로 만들어, 유저가 동률 후보에 포함되면 **자투
   버튼이 그대로 노출**됨(문서 1-1 '자투 금지'와 충돌).

## 조치 (v1.10)

| 항목 | 내용 |
|---|---|
| 투표 접수 후 즉시 닫기 | `_popup_vote`(기권 포함) 처리 끝에 `_mafia_overlay_close()` — 접수 즉시 투표 팝업이 사라져 잠금 대기를 없앰 |
| 재투표 후보 '나' 제외 | `_open_revote_popup`에서 `n == 내아이디`인 후보 버튼은 건너뜀 |
| 유일 후보 안전망 | tied에 '나'만 있어 선택지가 없는 경우 → 즉시 기권 개표로 진행(정지 방지) |

## 실측

```
팝업 띄움 → 유저 '지은' 클릭 → overlay 즉시 닫힘 → 채팅 입력 가능 상태 복귀
동률 후보 ['정민호','김과장'] → 버튼은 '김과장'만 노출(나 제외)
tied가 '나'뿐 → 기권 개표로 수동 전환(멈춤 방지)
```
