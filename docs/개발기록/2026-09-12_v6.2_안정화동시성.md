# v6.2 전체 코드베이스 안정화, 동시성 버그 해결 및 성능 최적화 (2026-09-12)

- **치명적 동시성 버그(데드락) 완전 해소**:
  - `engine.py:group_leave` 패킷 수신 처리 중 `with self.glock:` 내부에서 `self._save_groups()`를 호출하여 재귀적으로 `glock`을 획득하려다 발생하던 수신 스레드 및 메인 GUI 영구 정지(Freezing) 데드락 결함 해결.
  - `self.glock = threading.RLock()`으로 재진입 허용 락으로 격상하고, `self._save_groups()` 호출 위치를 락 블록 외부로 분리.
- **프로필 아바타 및 자리비움 상태 보존 결함 수정**:
  - `_upsert_peer`의 기본 인자 처리(`avatar_hash=None, status=None`)를 개편하여, 그룹 초대 수신이나 멤버 목록 파싱 시 아바타 정보가 누락된 패킷이 들어와도 기존에 설정된 상대방의 프로필 아바타 및 자리비움 상태가 빈값으로 덮어씌워져 증발하지 않도록 방어.
- **채팅 썸네일 렌더링 디스크 I/O 최적화 (`app.py:_load_thumbnail`)**:
  - `self._thumbnail_cache` 인메모리 캐시를 도입하여 `(path, mtime)`을 기준으로 이미 디코딩된 `tk.PhotoImage`를 보관(최대 64개 FIFO 관리).
  - 창 크기 조절(Resize), 대화방 전환, 스크롤 재렌더링 시 매번 하드디스크/SSD에서 이미지를 다시 읽고 디코딩하던 병목을 0ms로 단축.
- **메모리 누수 및 장기 실행 안정성 강화**:
  - 미완료 파일 수신 세션(`self.transfers_in`)에 타임스탬프를 부여하고, 3초 주기 `_prune()` 워커에서 120초 이상 경과된 미완료 세션을 자동 폐기하여 메모리 누수 원천 차단.
  - 아바타 요청 디바운스(`self._avatar_req_debounce`) 엔트리 중 60초 이상 경과된 키를 자동 정리.
  - Windows `GetTickCount` 49.7일 32비트 롤오버 방어를 위해 `(millis & 0xFFFFFFFF)` 마스킹 적용.
- **고아 코드 및 미사용 import 정리**:
  - 사이드바 애니메이션 리팩토링 후 남은 `app.py:_step_sidebar_anim` 빈 stub 함수 제거.
  - 전체 프로젝트에서 0회 호출되던 `netutils.py:korea_time_str_sec` 정리.
  - `netutils.py` 및 `canvas_utils.py`의 미사용 `import math` 제거.
