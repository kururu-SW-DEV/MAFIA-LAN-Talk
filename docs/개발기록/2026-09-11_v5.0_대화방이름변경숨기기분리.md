# v5.0 대화방 이름 변경, 대화 숨기기/기록삭제 분리, 접기 핸들 상하 확장(84px) & 슬라이딩 애니메이션 (2026-09-11)

- **대화방 이름 변경 기능**:
  - 그룹 대화방: 이름 변경 시 `groups.json` 저장 및 `group_invite` 패킷 팬아웃을 통해 **네트워크상의 모든 그룹원 PC 화면에서도 그룹명이 즉시 변경·동기화** (`Engine.rename_group`).
  - 1:1 대화방: 상대방의 브로드캐스트 이름 외에 내 화면에서 보여질 별칭(Alias) 설정 및 `settings.json` 영속 저장 (`Engine.set_alias`, `Engine.get_alias`). 빈칸 입력 시 원래 기본 이름으로 복원.
  - 채팅 헤더 제목 클릭, 헤더 ✏️ 버튼, 헤더 ⋮ 설정 메뉴, 사이드바 행 우클릭 메뉴 어디서든 편리하게 접근 가능.
- **대화 숨기기 vs 대화 기록 삭제 분리**:
  - 기존 사이드바 우클릭 메뉴의 "대화 삭제"를 "대화 숨기기"로 명확히 분리하여 상단 ☰ 메뉴의 [숨긴 대화 모두 표시]와 직관적으로 연동.
  - 영구 삭제를 원하는 사용자를 위한 "대화 기록 삭제" 메뉴를 신설하여, 사용자 확인(`askyesno`) 후 디스크의 `.jsonl` 대화 내역 파일을 영구 삭제하고 목록에서 숨김.
- **좌측 탭 숨기기 버튼 상하 길이 대폭 확장 (44px → 84px)**:
  - 분할 기둥의 `SplitterHandle` 세로 높이를 84px로 거의 2배 확장하여 마우스로 클릭하기 훨씬 편하도록 터치/클릭 타겟 대폭 확대.
  - 중앙 화살표 셰브론 위아래로 섬세한 그립 포인트 인디케이터를 배치하여 고급스러운 IDE 도크 핸들 룩 완성.
- **부드러운 슬라이딩 애니메이션 (`_step_sidebar_anim`)**:
  - 숨기기/펼치기 시 딱딱하게 즉시 전환되지 않고, 120ms Ease-Out 감속 곡선으로 부드럽게 미끄러지듯 사라지고 나타나는 네이티브 애니메이션 적용.
  - 애니메이션 진행 중에도 대화창 크기 및 말풍선 레이아웃이 자연스럽게 연동 조절됨.
