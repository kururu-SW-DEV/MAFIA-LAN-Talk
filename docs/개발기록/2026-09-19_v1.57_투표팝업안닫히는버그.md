# v1.57 — 투표 팝업이 안 닫히던 버그 수정 (2026-09-19)

## 사용자 지적
"투표 후 내가 변론대에 서게 되면 투표 창이 안내려감. 최하단의 안내
메시지가 실제 게임 상황에 맞지 않게 안내됨."

## 원인 (실측)

유저가 직접 투표 버튼을 클릭했을 때만(`_popup_vote`의 0.5초 뒤 자동 닫기)
투표 팝업이 실제로 닫혔다. 반면 **다른 경로**(예: 마지막 AI 표가 들어와서
자동으로 개표가 시작되는 `_schedule_tally`)로 개표가 진행될 때 호출되는
`_cancel_vote_popup()`은 타이머와 내부 참조(`_vote_lbl` 등)만 정리할 뿐,
실제 화면의 팝업 위젯(`_mafia_overlay`)은 전혀 닫지 않고 있었다. 본인이
최다 득표로 최후 변론대에 서는 것처럼 "내가 마지막으로 클릭한 게 아닌"
경로로 개표가 진행되면, 투표 팝업이 화면에 그대로 남아있었다. 그 위에
새로 뜨는 "재판 개시" 연출·안내 문구와 겹쳐 보여, 하단 안내 메시지도
상황과 안 맞는 것처럼 보인 것으로 판단(같은 근본 원인).

## 조치

`_cancel_vote_popup()`이 정리 작업 끝에 항상 `_mafia_overlay_close()`를
호출하도록 변경 — 어떤 경로로 호출되든 실제 팝업이 확실히 닫힌다
(`_mafia_overlay_close`는 열린 게 없으면 조용히 아무 일도 안 해서 중복
호출해도 안전).

## 검증

헤드리스로 투표 팝업을 연 뒤, 유저 클릭이 아닌 `_schedule_tally()` 경로로
개표를 트리거해 팝업이 실제로 닫히는지 재현 확인. 기존 회귀 테스트 3종
재실행 — 전부 통과.
