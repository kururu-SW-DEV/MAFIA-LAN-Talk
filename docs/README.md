# LAN Talk — 서버 없는 P2P LAN 메신저 (v6.37)

사내망 PC끼리 서버·지정 시스템 없이 직접 대화하는 파이썬 프로그램입니다.
외부 패키지 설치가 전혀 필요 없습니다 (Python 표준 라이브러리만 사용).

## 실행

1. Python(3.10 이상)이 설치된 PC라면 그대로 사용합니다.
2. `START_LAN Talk.bat` 더블클릭 → 최초 1회 Windows 방화벽 창이 뜨면 **[액세스 허용]** 클릭
   (회사·개인 네트워크가 나오면 둘 다. 앱이 로컬 네트워크에서 대화하기 때문입니다.)
3. 상대 방 PC에도 같은 폴더를 복사해 같은 방식으로 실행합니다.

기본 표시 이름은 Windows 계정명입니다. 상단에서 대화용 이름으로 언제든 바꿀 수 있습니다.
개별 설정 메뉴가 필요하면 명령행으로도 실행 가능합니다:

```
python lan_messenger.py --name 홍길동 --port 50707
```

## 상대 방 찾는 방법

- **같은 네트워크 구역(세그먼트)**: 킬 때마다 목록에 자동으로 들어옵니다. 아무 것도 안 해도 됩니다.
- **다른 구역**: 사이드바 상단 [＋] → [상대 연결]에서 상대 IP(예: `10.30.1.23` 또는 `10.30.1.23:50707`)를
  등록합니다. 두 PC 서로가 등록하면(한쪽만 등록해도 자동으로 아는 방식) 목록에서 대화가 열립니다.
- 내 PC의 IP 확인: 채팅창 우측 상단 [내 IP] — 다른 구역 동료에게 알려줄 때 참고용.
- SSH/VLAN 등으로 PC가 다중 IP이면 모두 표시합니다.

## 대화

- 왼쪽 목록에서 상대 선택 → 아래 입력 상자에 글 입력 → Enter(또는 [전송])
- 메시지는 수신 확인(ACK)을 받고, 실패하면 3회 재시도 후 빨강 안내를 보여줍니다.
- 대화 기록은 프로그램 폴더 밑 `data\logs\`에 JSON 파일로 저장됩니다(포터블 — USB 등으로
  폴더째 들고 다녀도 그 폴더 기준으로 항상 같은 기록을 찾습니다). 창을 다시 열었을 때
  (재실행 시) 이전 대화가 이어서 보입니다.
- 화면은 고급스러운 **티타늄 그레이 다크 테마**와 화이트 폰트가 적용되어 있습니다: 좌측 통합 대화 목록(1:1 + 그룹, 아바타·온라인 점·
  읽지 않음 배지·검색), 우측은 진짜 둥근 모서리 말풍선 채팅(내 메시지 블루, 상대는 흰색,
  날짜 구분선, 메시지 그룹핑), 하단 상태줄. 말풍선을 클릭하면 본문이 클립보드로 복사됩니다
  (일반 텍스트 드래그 선택은 지원하지 않아 대신 마련한 기능입니다).
- **단체대화방**: 상단 [＋] → [새 그룹 만들기]로 현재 목록에 있는 상대를 선택해 그룹을 만듭니다.
  서버가 없으므로 각자 알고 있는 멤버에게 개별 전송하는 방식이며, 대화하는 동안 멤버 정보가
  점차 전체에 퍼집니다(가십 전파). 그룹 채팅 헤더의 [멤버] 버튼으로 멤버 확인·추가가 가능합니다.
- **알림 팝업**: 창이 비활성 상태이거나 다른 대화를 보고 있을 때 새 메시지가 오면 Windows
  작업표시줄 풍선/토스트 알림이 뜹니다(외부 패키지 없이 표준 라이브러리 `ctypes`로 구현).
  상단에 작은 LAN Talk 공식 아이콘과 대화 내용만 깔끔하게 노출되며, 본문 하단의 불필요한
  중복 대형 아이콘을 제거하여 시각적 방해를 최소화했습니다.
- **대화/친구 삭제**: [채팅] 탭과 [친구] 탭 모두 목록 행을 우클릭하면 삭제할 수 있습니다(둘 다 같은
  방식 — 목록에서만 숨기고 대화 기록은 지우지 않습니다). 상대가 다시 메시지를 보내면 두 탭 모두에
  자동으로 되돌아옵니다. 아무 연락이 없어도 다시 보고 싶으면 사이드바 [＋] → [숨긴 대화 모두 표시]로
  한 번에 전부 되돌릴 수 있습니다.
- **친구 탭**: 사이드바 상단 [채팅]/[친구] 탭 전환. [친구] 탭은 현재 사내망에서 발견되었거나 등록된
  동료를 이름순으로 보여줍니다(그룹은 표시 안 함). 클릭하면 그 사람과의 1:1 대화가 열립니다.
- **친구 카테고리(폴더) 분류**: [친구] 탭에서 이름을 우클릭 → [📁 카테고리 지정]으로 "개발팀",
  "영업팀" 같은 카테고리를 만들어 배정할 수 있습니다. 목록이 카테고리별로 자동 그룹핑되어
  보이며(카테고리 없는 사람은 "미분류"로 맨 아래에 모입니다), 인원이 많아질수록 원하는 사람을
  훨씬 빠르게 찾을 수 있습니다.
- **여러 명에게 한 번에 보내기**: 사이드바 [＋] → [여러 명에게 한 번에 보내기]에서 대상을 체크박스로
  고르고 메시지를 한 번만 입력하면, 그룹을 새로 만들지 않고 선택한 사람들에게 각자 1:1로 개별
  전송됩니다. 공지를 한 번만 돌리고 싶을 때 매번 그룹을 만드는 번거로움이 없습니다.
- **프로필 사진**: 좌상단의 내 원형 프로필(이니셜)을 클릭하면 사진(PNG·GIF·BMP)으로 등록/변경하거나
  기본 이미지로 되돌릴 수 있습니다. 등록한 사진은 자동으로 원형으로 잘려 상대 PC에도 전파되어,
  대화 목록·채팅창에서 내 이니셜 대신 실제 사진으로 표시됩니다.
- **파일·사진 전송**: 입력창 옆 📎 버튼으로 파일을 첨부합니다. PNG·GIF·BMP·**JPG** 사진은
  카카오톡처럼 채팅창에 바로 미리보기로 나타나고, 그 외 파일(예: PDF, 문서 등)은 파일 이름·용량이
  적힌 카드로 표시됩니다. 이미지·파일 항목을 클릭하면 내 PC의 기본 프로그램으로 바로 열립니다.
  받은 파일은 기본적으로 프로그램 폴더 밑 `data\downloads`에 저장되며, 사이드바 [＋] →
  [다운로드 폴더 설정]에서 원하는 폴더로 바꿀 수 있습니다.
  - 파일 하나당 최대 20MB까지 보낼 수 있습니다(서버 없이 인원수만큼 직접 전송하는 구조라 보수적으로
    제한했습니다).
  - **전송이 끊기면 이어받기(resume)**: 상대가 오프라인이 되거나 앱을 껐다 켜서 전송이 중간에
    끊겨도, 받는 쪽에 이미 도착한 부분은 디스크에 그대로 남아있습니다. 같은 파일을 같은 상대에게
    다시 보내면 이미 받은 만큼은 건너뛰고 나머지만 전송되어, 큰 파일을 처음부터 다시 보낼 필요가
    없습니다.
  - **JPG는 어떻게 미리보기가 되나요? (v5.2)**: Python 기본 내장 tkinter는 JPG를 직접 못 읽지만,
    Windows 64비트 Python 3.14용 이미지 디코딩 라이브러리를 `vendor/pil_cp314/` 폴더에
    미리 통째로 담아뒀습니다. **설치·인터넷 연결이 전혀 필요 없고**, 폴더를 그대로 복사하기만
    하면 실행 중인 Python 버전에 맞는 폴더가 자동으로 쓰입니다(다른 파일들과 똑같은 방식).
    해당하는 버전이 없는 PC에서는 자동으로 건너뛰고 JPG가 지금처럼 파일카드로 표시될 뿐,
    오류가 나거나 앱이 죽지 않습니다.
- **클립보드 스크린샷 붙여넣기 (`Ctrl+V`)**: Windows 캡처 도구(`Win + Shift + S`)로 화면을 캡처하거나 이미지를 복사한 후 대화창 어디서든 `Ctrl+V`를 누르면 즉시 이미지 파일로 변환되어 대화방으로 전송됩니다.
- **URL 링크 자동 감지 및 원클릭 열기**: 메시지 본문 속 웹 주소(`http://`, `https://`)를 자동으로 파란색 하이라이트 링크로 표시하며, 더블 클릭 또는 우클릭 `[🔗 링크 열기]`로 기본 브라우저에서 바로 열립니다.
- **대화방 내 검색 (`Ctrl+F`)**: 대화방 상단 슬림 검색 바에서 키워드로 실시간 검색하고 해당 말풍선 위치로 즉시 스크롤 이동합니다 (`Enter` 다음 / `Shift+Enter` 이전 / `ESC` 닫기).
- **인용 답장 (Quote Reply)**: 말풍선을 우클릭하여 `[답장]`을 누르면 원본 메시지를 인용한 카드가 첨부된 답장을 보낼 수 있습니다.
- **카카오톡 스타일 읽음 확인 (`1` 배지)**: 내가 보낸 메시지 옆에 앰버색 `1` 숫자가 표시되며, 상대방이 대화방을 열어 확인하면 실시간으로 `1`이 사라집니다.
- **자동 폭파(자동 삭제) 메시지 (1:1 전용)**: 입력창 옆 `⏱` 버튼을 눌러 30초/5분/1시간 중 하나를
  고르면, 그 대화방에서 이후 보내는 메시지는 **상대가 읽은 시점부터** 지정 시간 뒤 양쪽 PC의
  대화 기록에서 자동으로 영구 삭제됩니다(다시 끄기 전까지 그 방에 계속 적용). 버튼 색이
  바뀌어 있는 동안은 타이머가 켜진 상태이니, 계속 켜둔 채 잊지 않도록 확인하세요. 사내
  계좌번호나 임시 비밀번호처럼 흔적을 남기고 싶지 않은 정보를 주고받을 때 유용합니다.
  (그룹 대화는 멤버마다 "읽음" 시점이 달라 이번 버전에서는 지원하지 않습니다.)
- **스티커 피커 (v6.28)**: 입력창 옆 `😊` 버튼을 누르면 입력창 바로 위에 오리지널 스티커 패널이
  펼쳐집니다(별도로 뜨는 팝업 창이 아니라 채팅창 안에 내장된 패널이라, 화면 밖으로
  벗어나거나 위치가 어긋나는 일이 없습니다). 복잡한 폰트 의존성을 없애고 28종 오리지널 스티커
  전용으로 최적화되었으며, 창 크기가 작아져도 스크롤바가 숨겨지지 않고 마우스 휠로 부드럽게
  탐색할 수 있습니다.
- **오리지널 스티커 28종 + 자동 추천 + 0초 즉시 로딩**: 카카오톡 "이모티콘"처럼 캐릭터를 사고파는 건
  저작권 문제로 못 하지만, 이 프로그램만의 표정·문구 스티커를 28종(표정 14 + 문구 14)
  자체 제작해 넣었습니다. `😊` 피커의 "스티커" 탭에서 골라 보내면 말풍선 없이 카톡처럼
  그림만 크게 뜨고, **입력창에 "점심", "축하", "굿모닝" 같은 키워드를 타이핑하면 어울리는
  스티커가 자동으로 위에 추천**되어 클릭 한 번으로 보낼 수 있습니다(타이핑 중인 글은
  그대로 남아있어 따로 전송 가능). 문구 스티커의 글자에는 흰색(또는 어두운) 테두리가
  둘러져 있어 배경색과 상관없이 항상 또렷하게 읽힙니다. 앱 기동 직후 백그라운드 사전 예열(Pre-warm)을
  적용하여 스티커가 많은 방에 들어가도 멈칫거림 없이 즉시 열립니다. 1:1·그룹 모두 지원하고 자동 폭파 타이머도 그대로
  적용됩니다.
- **사이드바 깜빡임 없는 매끄러운 갱신 (v6.28)**: 3초 주기 피어 감지 시 목록 순서 변경 여부를 판단(Diffing)하여
  전체 위젯을 뗐다 붙이지 않고 변경된 항목만 똑똑하게 갱신하므로, 화면 떨림이나 깜빡임이 전혀 없습니다.
- **선명한 고해상도 작업표시줄 아이콘 (v6.28)**: Windows 명시적 App ID와 다중 해상도(최대 256px) 네이티브
  아이콘을 적용하여, 파이썬 기본 로고나 저해상도 깨짐 현상 없이 선명한 LAN Talk 로고가 작업표시줄에 표시됩니다.
- **공지사항 고정 (카카오톡 스타일)**: 말풍선을 우클릭 → `[📌 공지로 등록]`을 누르면 그 메시지가
  대화방 상단에 배너로 고정 표시됩니다. 배너를 클릭하면 원본 메시지 위치로 스크롤 이동하고,
  배너의 `✕`를 누르면 해제됩니다(다시 우클릭 → `[📌 공지 해제]`도 가능). 1:1이든 그룹이든
  상대(들)에게도 똑같이 전파되어 모두 같은 공지를 봅니다 — 한 대화방에는 공지 1개만 유지되며
  새로 지정하면 이전 공지를 대체합니다.
- **오프라인 아웃박스 자동 재전송**: 상대방이 잠시 꺼져 있어 전송에 실패한 메시지는 내부 큐(`outbox.json`)에 보관되었다가, 상대방이 온라인으로 복귀하는 즉시 자동 재전송됩니다.
- **자리비움 (Away) 자동 전환**: 키보드·마우스 입력이 5분 이상 없을 경우 프로필 점이 자동으로 주황색(`자리비움`)으로 변경되어 상대방에게 부재 중임을 알립니다.
- **보스키 (Panic Hide / Restore)**: 업무 중 급히 화면을 가려야 할 때 `Ctrl + Shift + H` 또는 `F12`를 누르면 창과 작업표시줄 아이콘이 즉시 완전히 숨겨지고, 다시 누르면 원래대로 복원됩니다.

## 문제 해결

| 증상 | 원인/조치 |
|---|---|
| 목록에 상대가 안 나타남 | 같은 구역이 아니거나 방화벽 미허용 — [IP 직접 추가] 또는 관리팀에 **UDP 50707 수신 허용** 문의 |

## 단체대화방의 동작 방식 및 특징

서버가 없는 순수 P2P 구조에서 단체대화방을 가장 완벽하게 지원합니다:

- **오프라인 캐치업 (v6.3)**: 그룹 메시지를 보낼 때 특정 멤버가 오프라인이거나 PC가 꺼져 있어도, 해당 멤버 몫의 패킷이 로컬 `outbox.json`에 영속화되어 상대가 네트워크에 복귀(`presence`)하는 즉시 백그라운드에서 자동 재전송됩니다.
- **카카오톡 스타일 읽음 카운트다운 (v6.3)**: 발신 메시지 옆에 남은 안 읽은 인원수(예: `2`, `1`)가 주황색 숫자로 표시되며, 그룹원들이 방을 열 때마다 실시간으로 숫자가 줄어들고 전원이 읽으면 배지가 깔끔하게 사라집니다.
- **`@이름` 멘션 (v6.3)**: 입력창에서 `@`를 타이핑하면 그룹원 자동완성 팝업(`MentionPopup`)이 뜨며, 멘션된 메시지는 하늘색 테두리로 강조되고 수신자에게 `[멘션]` 전용 알림이 발생합니다.
- 새 멤버를 초대하면 초대한 사람의 최근 대화 50건을 함께 보내 맥락은 이어집니다.
- 그룹 탈퇴(나가기) 지원: 방을 나가고 싶을 때는 그룹 헤더의 `[⚙ 설정]` → `[🚪 그룹 나가기]`를 선택하면 다른 멤버들에게 퇴장 알림이 전달되고 대화방이 안전하게 정리됩니다.
- 그룹으로 파일을 보내면 멤버 수만큼 개별 전송되므로, 인원이 많거나 파일이 크면 시간이 다소 소요될 수 있습니다.

- **티타늄 그레이 다크 테마 & 화이트 텍스트 (v4.3)**: 세련된 메탈릭 다크 그레이와 깨끗한 화이트 텍스트 시스템으로 전면 개편.
- **기본 창 크기 9:16 비율(450×800) 및 최소화 크기 축소**: 데스크톱 화면에서 카카오톡처럼 컴팩트하게 배치할 수 있도록 9:16 비율 적용 및 `minsize`를 360×540으로 축소.
- **친구/대화 목록 호버링 개선**: 텍스트나 아바타 위를 지나갈 때 호버가 풀리던 깜빡임 현상을 자식 위젯 좌표 감지(`winfo_containing`)로 완전 해결.

## 검증 내역 (2026-09-11, v4.0)

- 두 대 PC 시뮬레이션에서 상호 발견 → 메시지 전송 → 수신확인(ACK) → 대화 기록 저장까지 전 단계 테스트 통과
- Windows UDP 특성(ICMP 도달불가 시 수신 스레드 사망) 방어 코드로 장시간 안정성 확보
- GUI 전체 조립 및 실제 위젯 상호작용(목록 선택, 입력, 전송, 수신 표시) 테스트 통과
- 그룹 채팅 프로토콜(초대 전파·메시지 팬아웃·멤버 간 가십 전파·뒤늦은 합류자 이력 스냅샷) 3~4자 엔진 시뮬레이션 통과
- `test_gui_flow.py`를 고정 딜레이 방식에서 조건 폴링 방식으로 재작성해 이전에 있던 간헐적 실패(사이드바가
  presence 갱신 때마다 destroy·재생성되며 클릭이 유실되는 경합)를 근본 수정 — 5회 연속 실행으로 안정성 확인
- Windows 트레이 풍선 알림 API(`Shell_NotifyIconW`) 호출이 예외 없이 성공하는 것까지 코드로 확인(실제 화면
  표시는 사용자 실행 화면에서 최종 확인 필요 — 자동화 환경에서는 OS 토스트 자체를 캡처할 수 없음)
- 대화 삭제(숨김) → 목록에서 사라짐 → 상대가 메시지를 보내면 자동 재등장 → [친구] 탭에서는 숨김과
  무관하게 항상 보이고 클릭하면 숨김이 풀리며 열림, 전 과정 GUI 테스트로 확인
- 파일 전송 프로토콜(오퍼→청크 분할 전송→조립→저장, 파일명 충돌 자동 넘버링, 20MB 초과 즉시 거부,
  그룹 파일 팬아웃)을 엔진 시뮬레이션으로 검증. GUI에서도 실제 `[+]` 첨부 버튼 경로(파일 선택 대화상자만
  모킹)로 일반 파일카드·PNG 인라인 미리보기가 캔버스에 실제로 그려지는 것까지 확인

## 보안 (v5.1)

이전 버전은 모든 대화·파일을 평문 UDP로 주고받아 같은 네트워크의 누구나 스니핑하거나
발신자 이름을 위조(스푸핑)할 수 있었습니다. v5.1부터는 `secret.key`(폴더에 최초 실행 시
자동 생성)를 사전 공유키로 써서 모든 패킷을 암호화하고 HMAC으로 서명·검증합니다.
**따라서 상대 PC에 폴더를 복사할 때 `secret.key`도 함께 복사해야** 서로 대화할 수 있습니다
(복사하지 않으면 서로 다른 키를 쓰게 되어 상대 목록에 아예 나타나지 않습니다 — 고장이
아니라 키가 다른 것입니다). 여전히 외부 패키지 없이 표준 라이브러리(`hmac`, `hashlib`,
`secrets`)만 사용합니다.

## 파일 구성

기존에는 단일 파일이었으나, 유지보수를 위해 v5.1부터 아래처럼 여러 파일로 나뉘었습니다.
전부 같은 폴더에 함께 배포되어야 합니다(상대 PC에 복사할 때 폴더 전체를 복사하면 자동으로
충족됩니다) — **단, `data/` 폴더만은 예외로, 내 개인 대화 기록이 들어 있으니 동료에게

`tests/`, `backup/`은 실행에 필요 없는 개발자용 폴더라 상대 PC에 복사하지 않아도 됩니다
(실수로 같이 복사해도 무해합니다).

| tests/ 안의 파일 | 설명 |
|---|---|
| test_headless.py | 네트워크 계층 무인 테스트 (개발용) — `python tests/test_headless.py`로 실행 |
| test_gui_flow.py | GUI 상호작용 테스트 (개발용) — `python tests/test_gui_flow.py`로 실행 |
| smoke_gui.py | GUI 조립 스모크 (개발용) — `python tests/smoke_gui.py`로 실행 |

테스트는 항상 프로젝트 루트를 기준으로 `lan_messenger.py`를 동적 로드하므로, 어느 위치에서
실행해도(`tests/` 안에서든 프로젝트 루트에서든) 정상 동작합니다.
